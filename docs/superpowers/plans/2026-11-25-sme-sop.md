# SME SOP 라이브러리 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the SME course "SME SOP 라이브러리" (8 procedures on a numbered list) and connect it to SME Learn, my learning, today's practice, backup and reset, without changing what unlocks the SME review quiz.

**Architecture:** A new course folder `sme-sop/` built like `sme-lifecycle/` (lesson files on the shared lesson engine and player), with a numbered-list first screen like the SOP Library's (one list, no groups, a "누가" line per card). The course joins `COURSE_INFO`, `ROLE_COURSES.sme` and home's `LEARN`; `REVIEW_COURSES.sme` stays `['sme']`. With all three SME courses built, home has no SME coming-soon Learn card left.

**Tech Stack:** Static vanilla ES modules; `cd agent-lifecycle && npm test` (node:test + jsdom); `python3 agent-lifecycle/scripts/browser_check.py` (Playwright); `python3 tools/sw_list.py` after runtime file changes.

**Spec:** `docs/superpowers/specs/2026-11-25-sme-learn-set-design.md` §4.3, §4.4 · Korean copy (approved): `docs/superpowers/specs/2026-11-25-sme-sop-copy-ko.md`

## Global Constraints

- Korean text equals the approved copy word for word; tests read it from the copy doc.
- Step captions: 3 sentences or fewer; a figure in a caption carries "예시" (`SME_FIGURE`).
- Lesson ids have no hyphen: `approval`, `scrubbing`, `trend`, `attendance`, `huddle`, `calibration`, `voc`, `kbrequest`.
- Course id `sme-sop`, folder `sme-sop/`, progress key `sme-sop:v1`.
- Persona names: 서준 (lesson 2), 준호 (lesson 4), 수진 (lesson 5); the default 지민 elsewhere.
- SME review quiz still unlocks with SME 첫걸음 only (design §4.4).
- English copy and any new wording (privacy row, the Support Lifecycle closing line) need the user's approval before push; commit/push/merge each need approval.
- Regenerate `sw.js` with `python3 tools/sw_list.py` after any runtime file change.

## Review Focus

1. With the SME quiz unlocked by SME 첫걸음 alone, finishing or not finishing SME SOP lessons never changes it → Task 3 test `the SME quiz still opens with SME First Steps alone` (extended with `sme-sop`).
2. A practice question from this course links to `../sme-sop/#<id>-0`, not the team-lead SOP Library (`../sop-library/`), even where both courses have a scrubbing/calibration lesson → Task 3 test `SME SOP questions link to their own course`.
3. Old addresses (`#home`, `#escalation-2`, `#pip-0`, `#approval-99`) open the list or the lesson's last step without errors → Task 2 test `stale addresses open the list`.
4. A backup made before this course (no `sme-sop:v1`) restores; reset erases this course's progress and keeps the role → Task 3 test `backup and reset include SME SOP progress`.
5. A team lead never sees this course in Learn or my learning, but progress in it still counts as "started"; an SME's Learn has no coming-soon card left → Task 3 tests `team leads do not see SME SOP but its progress counts`, `SME Learn links to all three SME courses`.
