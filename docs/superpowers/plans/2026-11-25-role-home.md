# 직급별 홈과 찾아보기 페이지 (①) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every role gets the same home layout with its own guide card and Learn cards (unbuilt ones as "coming soon"), Browse moves to its own page, role labels use TL/AM/OM, and SMEs see no advanced Excel.

**Architecture:** One data table (`home/role-home.js`) says, per role, which guide card and Learn cards to show and which are ready. Home renders only that table. A new `browse/` page holds the four Browse cards; the bottom menu points there. Excel and practice ask one function whether the role sees advanced Excel.

**Tech Stack:** Vanilla ES modules; `cd agent-lifecycle && npm test`; `python3 agent-lifecycle/scripts/browser_check.py`; `python3 tools/sw_list.py`.

**Spec:** `docs/superpowers/specs/2026-11-25-sme-learn-set-design.md` §4.1 · copy: `docs/superpowers/specs/2026-11-25-role-home-copy.md` (ko+en, approved 2026-11-25)

## Global Constraints

- Wording exactly as the copy doc, both languages. Short role names: 상담사/Agent, SME, TL, AM, OM. Full names only in the role sheet, Settings "내 직급" and the glossary (copy §8).
- Lesson body sentences, Codex one-pagers and team-lead course names are not changed.
- Home order for every role: Miso → 내 학습 → 오늘의 연습 → 상황별 길잡이 → 배우기. No Browse section on home.
- Learn per role: TL = lifecycle, SOP, Excel. SME = SME 첫걸음, 서포트 라이프사이클 (soon), SME SOP 라이브러리 (soon), Excel. Agent/AM/OM = ○○ 첫걸음 (soon), ○○ SOP 라이브러리 (soon), Excel.
- Guide card: TL = link to `./guide/`; others = "coming soon".
- "Coming soon" cards are not links, carry the 준비 중 mark and two Codex links (`./codex/#career`, `./codex/#daily-<role>`).
- Advanced Excel hidden only for SME; stored advanced progress is kept.
- Branch `sme-learn-set`; push and PR only with owner approval.

## Review Focus

1. An SME opens an advanced Excel address (`excel/#lesson-12`) → lands on the Excel list, no advanced section (Task 4 `an SME never sees advanced Excel`).
2. An SME who already finished advanced lessons keeps that progress, and practice gives them no advanced questions (Task 4 `advanced progress is kept but not asked`).
3. A learner arrives at the old address `./#browse` (bookmark, old tour) → is sent to the Browse page, not a blank home (Task 3 `the old browse address opens the browse page`).
4. A "coming soon" card can't be activated by keyboard and is read as coming soon (Task 2 `coming-soon cards are not links and say so`).
5. Changing the role in Settings and coming back changes home cards without a reload error (Task 2 `each role's home has the same sections in the same order`).
