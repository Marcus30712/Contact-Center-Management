# SME 상황별 길잡이 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the SME Situation Guide page `sme-guide/` (16 situations in 5 groups) on the team-lead guide's screen code, and send SMEs there from the home card and the bottom menu, with the lesson-end "then go here" card working in the three SME courses.

**Architecture:** `guide/render.js` takes its title/intro and groups as an argument (default: the TL data, so the TL page is unchanged). `sme-guide/data.js` holds the SME data; `sme-guide/app.js` renders it. `guide/link.js` knows both situation lists, and the three SME course apps call `settleGuide` like the TL courses. The bottom menu picks the guide address by role.

**Tech Stack:** Static vanilla ES modules; `cd agent-lifecycle && npm test` (node:test + jsdom); `python3 agent-lifecycle/scripts/browser_check.py`; `python3 tools/sw_list.py` after runtime file changes.

**Spec:** `docs/superpowers/specs/2026-11-25-sme-guide-design.md` (approved, with the Korean copy in §5)

## Global Constraints

- Korean equals the design doc §5 word for word; tests read the doc.
- Situation ids `m1`–`m16`; the TL guide's `s1`–`s18`, its address and its tests stay as they are.
- Link titles of SME lessons are "<course> 레슨 N · <lesson title>" (SME SOP: "SME SOP · <title>") and must equal the current lesson titles in both languages.
- Shared guide strings (먼저 볼 곳, 이어서 볼 곳, 묶음 고르기, {group}: 상황 {n}개, lesson-end card) come from `GUIDE_UI`; only title and intro are SME's own.
- English needs the user's approval before push; commit/push/merge each need approval.
- Regenerate `sw.js` after runtime file changes.

## Review Focus

1. The TL guide is unchanged: `guide/` renders the same 18 situations, title and intro; existing guide tests pass untouched → Task 2 test `the TL guide renders as before`.
2. `?guide=m3` on `sme-lifecycle/#trainee-0` shows the "then" card; on another lesson it is dropped; `?guide=s1` on an SME lesson is ignored → Task 3 tests `guideFor finds SME situations only on their own lesson`, `the SME course apps settle the guide`.
3. Bottom menu: an SME gets `./sme-guide/`, every other role (and blocked storage) gets `./guide/`; both pages mark Guide as current → Task 3 test `the menu's Guide follows the role`.
4. Odd addresses on `sme-guide/` (`#s1`, `#m99`, `#learn`) show the list without errors → Task 2 test `odd addresses show the list`.
5. A lesson title change in an SME course would make its guide link name stale → Task 1 test `SME lesson link names are the current lesson titles`.
