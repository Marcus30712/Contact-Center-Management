# AM SOP Library Implementation Plan

**Goal:** Build "부매니저 SOP 라이브러리 / AM SOP Library" (8 procedures) at `am-sop/` and open it from the AM home in place of the "준비 중" SOP card.
**Architecture:** Same structure as the Agent SOP Library (`agent-sop/`): list page, lessons with a 4-node figure, a "누가" chain, 8 steps and a 2-question AM checkpoint, generated from the approved copy docs by a scratch generator; tests compare code to docs word for word.
**Tech Stack:** Static vanilla ES modules, node:test + jsdom, Playwright browser check.
**Spec:** `docs/superpowers/specs/2026-11-28-am-sop-design.md`, `2026-11-28-am-sop-copy-ko.md`, `2026-11-28-am-sop-copy.en.md`.
