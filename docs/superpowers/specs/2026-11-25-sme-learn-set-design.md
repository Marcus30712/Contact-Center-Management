# 직급별 홈과 "배우기", 찾아보기 페이지, SME 전용 강의 — 설계 문서

작성일: 2026-11-25 · 상태: 승인됨 (2026-11-25) · 앞선 설계: `2026-11-25-role-select-sme-course-design.md`, `2026-11-25-role-review-quiz-design.md`

## 1. 의도와 이유

직급마다 "배우기"에 보이는 강의를 따로 정합니다. 다른 직급의 강의는 보이지 않습니다. 그리고 어느 직급이든 홈의 구역과 순서를 같게 맞춰, 직급을 바꿔도 낯설지 않게 합니다(사용자, 2026-11-25).

사용자가 정한 것:
- **배우기는 직급별로 둡니다.** 모든 직급이 "직급 첫걸음, 그 직급의 SOP 라이브러리, 미소의 엑셀 연습"이라는 같은 틀을 씁니다. 팀장은 첫걸음 자리를 상담사 라이프사이클이 대신하고, SME는 첫걸음과 서포트 라이프사이클을 둘 다 가집니다(선택 A).

  | 직급 | 배우기 |
  |---|---|
  | 팀장 | 상담사 라이프사이클 · SOP 라이브러리 · 미소의 엑셀 연습 |
  | SME | SME 첫걸음 · 서포트 라이프사이클 · SME SOP 라이브러리 · 미소의 엑셀 연습 |
  | 상담사·부매니저·매니저 | ○○ 첫걸음 (준비 중) · ○○ SOP 라이브러리 (준비 중) · 미소의 엑셀 연습 |

- **찾아보기는 홈에서 뺍니다.** 아래 메뉴의 찾아보기 아이콘을 누르면 별도 페이지에서 Codex, 인력 산정 실험실, 용어집, 참고 자료 카드를 봅니다.
- **홈의 틀을 모든 직급에 통일합니다**(승인). 구역과 순서는 같고 내용만 직급에 맞게 바뀝니다. 빈자리는 "준비 중" 카드로 채웁니다.
- **SME 전용 강의 두 개**를 새로 만듭니다.
  - 서포트 라이프사이클: 상담사 한 사람이 교육 중 → 교육 수료(실무 체험) → 정식 상담사 → 선임으로 자라는 동안, 단계마다 SME가 따르는 지원 절차를 배웁니다. 마지막 단계는 팀장 지원입니다.
  - SME 첫걸음과의 구분: SME 첫걸음은 SME가 된 직후의 적응(역할, 승인 권한, 관계)이고, 서포트 라이프사이클은 대상별 절차와 순서입니다.
  - SME SOP 라이브러리의 절차 8개: 에스컬레이션 승인, 스크러빙, 상담 트렌드 요약 보고, 출석 관리 대행, 고객사 업데이트 허들, 캘리브레이션 참여와 기준 전달, 고객의 소리(VOC) 리포팅, 지식 베이스 업데이트 요청.
- **SME 엑셀**: 같은 강의이고, 카드 설명만 "SME가 꼭 쓰는 엑셀 11가지"로 바꿉니다. 심화 문제는 SME에게 보이지 않습니다.
- **SME 복습 퀴즈**는 지금처럼 SME 첫걸음만 마치면 열립니다.
- **진행 순서**: ① 홈 통일, 직급별 배우기, 찾아보기 페이지, SME 엑셀 → ② 서포트 라이프사이클 → ③ SME SOP. 단계마다 문안을 승인받고 배포합니다.

## 2. 목표 · 비목표 · 반목표

**목표**
- 모든 직급의 홈이 같은 구역, 같은 순서입니다: 김미소 인사 → 내 학습 → 오늘의 연습 → 상황별 길잡이 → 배우기.
- "배우기"에는 내 직급 카드만 보입니다(위 표). 아직 없는 강의는 "준비 중" 카드로 같은 자리에 보입니다.
- 상황별 길잡이 카드: 팀장은 지금의 팀장 상황별 길잡이, 다른 직급은 "○○ 상황별 길잡이 (준비 중)" 카드입니다.
- 찾아보기 페이지(`browse/`)에 Codex, 인력 산정 실험실, 용어집, 참고 자료 카드가 있습니다. 아래 메뉴의 찾아보기가 이 페이지로 갑니다. 홈에는 찾아보기 구역이 없습니다.
- SME에게 엑셀 카드 설명은 "SME가 꼭 쓰는 엑셀 11가지…"이고, 엑셀 페이지와 오늘의 연습에 심화가 나오지 않습니다.
- 서포트 라이프사이클과 SME SOP는 레슨 엔진을 쓰는 강의로 진도, 오늘의 연습, 백업, 학습 초기화, "내 학습"에 연결됩니다.

**비목표**
- 팀장용 라이프사이클·SOP의 내용, 이름, 주소를 바꾸는 것.
- 상담사·부매니저·매니저의 첫걸음, SOP, 길잡이 내용. 카드만 "준비 중"으로 둡니다.
- SME 상황별 길잡이의 내용. 카드만 "준비 중"으로 둡니다.
- SME 복습 퀴즈에 새 문제를 넣는 것.
- 엑셀 레슨 11개의 내용을 SME용으로 다시 쓰는 것.

**반목표**
- 직급을 바꿨을 때 홈의 구역이 생기거나 사라지는 것.
- 다른 직급 강의를 주소로도 못 열게 막는 것. "배우기"에서만 빠지고 주소·Codex·길잡이 링크로는 그대로 열립니다.
- 이미 푼 엑셀 심화 기록, 다른 직급 강의 진도가 지워지는 것.
- SME 첫걸음과 서포트 라이프사이클이 같은 장면을 반복하는 것.

## 3. 접근 방식

| 방법 | 내용 | 결정 |
|---|---|---|
| A. 새 강의 폴더 + 직급별 카드 목록 | `sme-lifecycle/`, `sme-sop/` 폴더, 직급마다 홈 카드 목록 | **사용자 선택**: SME 첫걸음에서 검증한 방식이고 다음 직급에도 그대로 씁니다 |
| B. 기존 강의 안에 "팀장/SME" 전환 | 라이프사이클·SOP 레슨 하나에 직급별 문장 | SME 강의의 단계와 절차가 팀장 강의와 주제가 달라 억지로 맞추게 됩니다 |

## 4. 무엇이 바뀌나

### 4.1 ① 홈 통일, 직급별 배우기, 찾아보기 페이지, SME 엑셀 (첫 배포)
- **직급별 카드 표**: 직급마다 길잡이 카드 하나와 배우기 카드 목록을 한곳(`shared/role.js` 옆)에 둡니다. 카드는 "준비됨(링크)" 또는 "준비 중"입니다.
  - 팀장: 길잡이 = 팀장 상황별 길잡이 / 배우기 = 라이프사이클, SOP, 엑셀
  - SME: 길잡이 = SME 상황별 길잡이(준비 중) / 배우기 = SME 첫걸음, 서포트 라이프사이클(①에서는 준비 중), SME SOP(①에서는 준비 중), 엑셀
  - 상담사·부매니저·매니저: 길잡이 = ○○ 상황별 길잡이(준비 중) / 배우기 = ○○ 첫걸음(준비 중), ○○ SOP 라이브러리(준비 중), 엑셀
- **"준비 중" 카드**: 링크가 아니고 흐리게 보이며, "준비 중" 표시가 있습니다. 설명 문장에 Codex 커리어 매트릭스와 직무별 하루 링크를 넣어 그동안 볼 곳을 알려 줍니다. 지금 홈의 별도 "준비 중" 안내 문단은 없앱니다.
- **카드 이름**: "직급 이름 + 같은 말"로 맞춥니다(SME 첫걸음, 상담사 첫걸음, SME SOP 라이브러리…). 팀장용은 지금 이름을 그대로 둡니다.
- **찾아보기 페이지 `browse/`**: 지금 홈의 찾아보기 카드 4장을 그대로 옮깁니다. 아래 메뉴의 찾아보기가 이 페이지를 가리키고, 이 페이지에서 찾아보기 탭이 켜집니다. 홈에서는 찾아보기 구역이 사라집니다. Codex, 실험실, 용어집, 참고 자료 페이지에서도 아래 메뉴는 찾아보기가 켜진 채로 둡니다.
- **SME 엑셀**: 엑셀 카드 설명은 직급에 따라 바뀝니다. 엑셀 페이지는 SME에게 심화 구역을 보이지 않고, 주소로 심화 레슨에 들어오면 엑셀 첫 화면으로 보냅니다. 오늘의 연습은 SME에게 심화 문제를 내지 않습니다. 오늘 이미 뽑힌 문제는 그날까지 둡니다.
- **처음 방문 안내와 "내 학습"**: 지금처럼 내 직급 강의와 엑셀만 보입니다. 처음 방문 안내는 직급의 첫 강의를 가리킵니다(팀장: 라이프사이클 레슨 1, SME: SME 첫걸음 레슨 1, 강의가 없는 직급: 엑셀 레슨 1, 문구는 문안 단계에서 확정).

### 4.2 ② 서포트 라이프사이클 (`sme-lifecycle/`)
- 첫 화면은 팀장용 라이프사이클처럼 원형 다이어그램과 단계 목록입니다. 트랙 전환은 없습니다.
- 단계(제안): 교육 중 → 교육 수료(실무 체험) → 정식 상담사 → 선임 → 팀장 지원. 레슨 5개, 판단 문제 2개씩입니다. 단계와 문장은 문안 단계에서 확정합니다.
- 각 레슨은 그 단계에서 SME가 무엇을 확인하고, 무엇을 기록하고, 언제 팀장에게 넘기는지를 스텝으로 보여 줍니다.
- 인물: 서준이 단계를 따라 자라고, 선임 단계에는 준호, 팀장 지원 단계에는 수진 팀장이 나옵니다. 시점은 "당신 = SME"입니다.
- 배포하면 SME 배우기의 "서포트 라이프사이클" 카드가 링크로 바뀝니다.

### 4.3 ③ SME SOP 라이브러리 (`sme-sop/`)
- 첫 화면은 팀장용 SOP 라이브러리처럼 번호 목록입니다. 절차 8개를 순서대로 둡니다.
- 각 절차는 SOP 레슨 형식입니다. 목적과 단계를 다이어그램으로 보여 주고 체크포인트 2문제로 끝납니다. 팀장 SOP와 같은 절차는 SME가 맡는 부분만 다룹니다.
- 배포하면 SME 배우기의 "SME SOP 라이브러리" 카드가 링크로 바뀝니다.

### 4.4 연결
- 직급 표에서 SME가 배우는 강의를 ②, ③ 배포 때 `sme`, `sme-lifecycle`, `sme-sop`로 넓힙니다. "내 학습"에도 함께 보입니다.
- 복습 퀴즈의 잠금은 직급 표와 따로 둡니다. SME 퀴즈는 SME 첫걸음만으로 열립니다.
- 새 진도 키 `sme-lifecycle:v1`, `sme-sop:v1`는 백업과 학습 초기화에 넣고, 개인정보처리방침의 레슨 진도 문구도 고칩니다.
- 아래 메뉴에서 새 강의 폴더는 "배우기", `browse/`는 "찾아보기"에 속합니다.

## 5. 진행 순서

1. 이 설계 승인
2. ① 문안(직급별 카드 이름·설명, "준비 중" 카드, SME 엑셀 설명, 처음 방문 안내, 찾아보기 페이지 제목) 확인 → 구현 → PR
3. ② 서포트 라이프사이클 한국어 문안 → 구현 → 영어 → PR
4. ③ SME SOP 라이브러리 한국어 문안 → 구현 → 영어 → PR

단계마다 별도 브랜치와 PR이고, 커밋·푸시·합치기는 매번 승인받습니다.

## 6. 완성 기준

- 직급을 바꿔도 홈의 구역과 순서는 같고, 길잡이 카드와 배우기 카드만 바뀝니다. 팀장에게 SME 카드가, SME에게 팀장 카드가 보이지 않습니다.
- 홈에 찾아보기 구역이 없고, 아래 메뉴의 찾아보기는 `browse/`를 열어 카드 4장을 보여 줍니다.
- "준비 중" 카드는 누를 수 없고 화면 낭독기가 "준비 중"이라고 읽습니다.
- SME에게 엑셀 심화가 어디에도 나오지 않고, 이미 푼 심화 기록은 남아 있습니다.
- 서포트 라이프사이클과 SME SOP 레슨을 끝까지 넘길 수 있고, 마친 레슨의 문제가 오늘의 연습에 나옵니다.
- 전체 테스트와 브라우저 점검이 통과합니다.

## 7. 빌더에게 맡기는 것 (제안한 결정)

- 직급별 카드 표는 데이터 한 곳에 두고, 홈은 그 표만 읽어 그립니다.
- 처음 튜토리얼에서 "찾아보기" 단계는 아래 메뉴 아이콘을 가리키도록 문구를 확인합니다(문안 단계).
- 엑셀 페이지와 오늘의 연습은 같은 함수로 "이 직급에 심화를 보여 줄지"를 판단합니다.
- 서포트 라이프사이클은 팀장용 라이프사이클의 원형 첫 화면 코드를 트랙 전환 없이 다시 씁니다.
