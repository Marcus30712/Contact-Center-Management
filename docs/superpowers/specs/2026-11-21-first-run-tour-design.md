# 처음 사용자 튜토리얼 (아래 메뉴 짚어 주기) — 설계

- 날짜: 2026-11-21
- 상태: 설계·한국어 문구 승인 (2026-11-21)
- 크기: 작은 변경 (짧은 설계)

## 의도

처음 온 사람이 아래 메뉴 다섯 칸(홈·배우기·길잡이·찾아보기·설정)이 **어디에 있고 각각 무엇인지** 한 줄씩 익히게 한다. 원하지 않으면 언제든 '건너뛰기'로 닫는다.

- 목표: 메뉴 다섯 칸의 위치와 한 줄 설명을 익히기.
- 하지 않을 것: 레슨 내용 안내, 페이지별 안내, 첫 레슨 강제 시작.
- 실패로 볼 것: 닫을 수 없거나 매번 다시 뜨는 것, 말풍선이 메뉴를 가리거나 화면 밖으로 나가는 것, 키보드·화면 읽기 프로그램으로 쓸 수 없는 것.

## 방법 (검토한 것)

| 방법 | 내용 | 결정 |
|---|---|---|
| A. 아래 메뉴 짚어 주기 | 화면을 어둡게 하고 실제 메뉴 한 칸만 밝게, 그 위에 김미소 말풍선 | **선택** — 실제 위치를 보여 주므로 목표에 가장 맞음 |
| B. 소개 카드 넘기기 | 가운데 카드에 메뉴 그림과 한 줄 설명 | 만들기 쉽지만 위치는 그림으로만 보여 줌 |
| C. 페이지별 첫 방문 안내 | 각 페이지에서 따로 안내 | 다섯 칸을 다 보려면 여러 번 이동해야 해서 뺌 |

## 동작 (승인됨)

- **언제:** 홈(`index.html`)을 열었을 때 "튜토리얼 봤음" 값이 없으면 한 번 뜬다. 다른 페이지에서는 뜨지 않는다.
- **진행:** 홈 → 배우기 → 길잡이 → 찾아보기 → 설정 순서. 한 번에 한 칸만 밝게, 그 칸 위에 말풍선.
- **말풍선:** 김미소 얼굴, 한 줄 설명, 진행 표시 "n/5", [건너뛰기] [다음]. 마지막 장은 [다음] 대신 [시작하기].
- **끝:** 건너뛰기·시작하기·Esc 모두 "봤음"으로 저장하고 닫는다.
- **다시 보기:** 설정 페이지에 "튜토리얼 다시 보기" 버튼. 누르면 홈으로 가서 처음부터 다시 보여 준다.
- **접근성:** 말풍선은 대화상자로 읽히고, 열리면 초점이 말풍선 안으로 간다. 닫히면 원래 자리로 돌아간다. Esc는 건너뛰기와 같다.
- **움직임 줄이기:** 기기에서 켜져 있으면 넘어갈 때 움직임 효과를 넣지 않는다.

## 저장과 개인정보 (제가 정한 부분, 승인됨)

- 새 저장 값 1개: `queuecraft:tour` = `"done"` (try/catch).
- 저장이 막힌 브라우저에서는 "봤음"을 기억할 수 없어 홈에 올 때마다 다시 뜨게 되므로, 자동으로 띄우지 않는다. 설정의 "튜토리얼 다시 보기"로는 볼 수 있다. (2026-11-21 검토 뒤 변경)
- 기록 백업(`BACKUP_KEYS`)에는 넣지 않는다. 학습 기록이 아니기 때문. 기기를 바꾸면 한 번 더 뜰 수 있다.
- 개인정보처리방침 `s2.item1` 변경. 저장 개수를 세는 개인정보 테스트(현재 7)는 새 값에 맞춘다.

## 만드는 사람에게 맡기는 것

- 파일 배치(예: `shared/tour.js`, `shared/tour.css`)와 말풍선 위치 계산 방식. 단, 말풍선은 화면 안에 있어야 하고 밝게 표시한 메뉴 칸을 가리지 않아야 한다.
- 설정 페이지에서 버튼을 놓을 자리.
- "다시 보기"로 홈에 신호를 넘기는 방법(예: 값 지우기 후 이동, 또는 주소 표시).
- 테스트: 문구는 이 문서의 표와 비교하는 테스트로 묶는다(기존 문안 대조 방식). 저장 값, 건너뛰기, 마지막 장, Esc, 다시 보기, 저장이 막힌 경우를 테스트한다. 브라우저 확인에 말풍선이 화면 안에 있고 해당 메뉴 칸 위에 있는지 측정을 추가한다.
