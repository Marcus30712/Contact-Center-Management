# 오늘의 연습에 엑셀 문제 섞기 — 짧은 설계

작성일: 2026-11-20 · 사용자 승인: "남은 작업들을 추천하는 옵션으로 진행" (2026-11-20)

## 목적
마친 엑셀 레슨도 "오늘의 연습"에서 복습한다. 3단계 설계에서 나중으로 미룬 일이다.

## 정한 것 (추천안으로 결정)
- **넣는 문제**: 마친 엑셀 레슨의 **객관식과 빈칸**만 넣는다(레슨마다 4문제, 11개 레슨이면 44문제). 2026-11-21 추가(승인): 마친 심화 레슨(12~16)의 객관식·빈칸도 같은 방식으로 넣는다(5개 레슨, 20문제). '엑셀 완주' 배지와 홈 '내 학습'은 기본 11개 기준 그대로. 수식 카드 조립·칸 누르기·단계 맞추기는 넣지 않는다. 연습 화면은 짧게 푸는 곳이라, 손이 많이 가는 문제는 엑셀 레슨에서 한다.
- **표**: 엑셀 문제가 나오면 문제 아래에 "미소 팀 하루 콜 기록"(예시) 표를 보여 준다. 빈칸 문제는 수식 줄(`=COUNTIF(D2:D9, ___)`)도 보여 준다.
- **보기 순서**: 엑셀 레슨과 같은 순서로 섞어서 보여 준다(정답이 늘 첫 번째가 되지 않게).
- **고르는 순서**: 지금처럼 틀린 문제 → 처음 보는 문제 → 오래된 문제. 강의 구분 없이 함께 섞는다.
- **문제 이름**: `excel:<문제 번호>` (예: `excel:4-3`).
- **틀렸을 때 링크**: 해당 엑셀 레슨(`../excel/#lesson-N`).
- **새 문구 없음**: 질문, 보기, 해설, 표 제목은 모두 확정된 엑셀 문안을 그대로 쓴다.

## 방법 비교
| | 방법 | 얻는 것 | 잃는 것 |
|---|---|---|---|
| **A (선택)** | 객관식·빈칸만, 표 함께 보여 줌 | 기존 연습 화면에 표만 더하면 됨, 빠르게 풂 | 조립 문제 복습은 레슨에서 |
| B | 조립·칸·단계까지 모두 | 모든 종류 복습 | 연습 화면에 엑셀 화면 전체를 다시 만들어야 함, 하루 몇 분 목표와 안 맞음 |
| C | 엑셀 전용 "오늘의 엑셀" | 분리가 분명 | 연속 학습·배지가 나뉨 |

## 확인
- 테스트: 엑셀 문제가 열리는 조건(마친 레슨, 객관식·빈칸만), 문제 이름, 보기 섞기와 채점, 표·수식 줄 표시, 레슨 링크, 영어 화면.
- 브라우저 점검: 엑셀 레슨을 마친 상태에서 연습 화면에 표가 넘치지 않는지(320px).
