# 미소의 엑셀 연습: 심화 (함수 섞어 쓰기) — 설계

작성일: 2026-11-21 · 상태: 방법 A·조합 5개와 순서 승인 2026-11-21 · 한국어 문안: 레슨 12~16 승인 2026-11-21 · 조립 카드 한도 22장(심화만) 승인 2026-11-21

## 의도

기본 11개 레슨에서 함수를 하나씩 익힌 사람이 **배운 함수를 한 수식 안에서 섞어 쓰는 실력**을 키운다(사용자 목표, 2026-11-21).

- 목표: 함수 안에 함수를 넣는 수식을 읽고, 빈칸을 채우고, 카드로 조립한다.
- 하지 않을 것: 기본 11개 레슨·점수·기록 변경, 새 표(예시 표 그대로), KPI 가중치 점수(SUMPRODUCT, 나중에 따로).
- 실패로 볼 것: 기존 학습 기록이나 홈의 '다 마침'이 바뀌는 것, 오답 칩이 우연히 정답과 같은 값을 내 맞다고 채점되는 것, 수치를 "예시" 없이 기준처럼 쓰는 것.

## 방법 (승인됨)

| 방법 | 결정 |
|---|---|
| A. 기본 11개 뒤에 '심화' 묶음 | **선택** — 기존 과정·기록을 건드리지 않고 한곳에서 단계적으로 |
| B. 레슨마다 도전 문제 | 문제 수·점수·기록이 바뀜 |
| C. 오늘의 연습에 넣기 | 복습 자리라 새 실력을 익히기에 맞지 않음 |

## 레슨 (승인됨)

| # | 레슨 | 섞는 함수 | 열리는 조건 |
|---|---|---|---|
| 12 | 조건 집계로 판정하기 | IF + COUNTIFS | 4·6번 마침 |
| 13 | 비율을 반올림해 판정하기 | IF + ROUND + 비율 | 3·6번 마침 |
| 14 | 두 조건으로 판정하기 | IF + AND / OR | 3·6번 마침 |
| 15 | 찾을 값이 없을 때 대비하기 | IFERROR + XLOOKUP | 7번 마침 |
| 16 | 팀 평균 처리 시간 구하기 | SUMIFS + 나누기 + TEXT | 5·8번 마침 |

## 정한 부분 (승인됨)

- 형식은 기본 레슨과 같다: 설명 카드, 6문제(객관식 2 · 빈칸 2 · 수식 조립 2), 요약. 오답 보기·칩마다 피드백 한 문장, 조립 문제는 만든 수식의 결과를 보여 준다.
- 목록 화면: 11개 아래에 '심화' 구역. 잠긴 레슨은 "○·○번 레슨을 마치면 열려요".
- 홈 '내 학습'의 엑셀 줄은 기본 11개 기준 그대로. 심화 진도는 엑셀 연습 안에서만 보인다.
- 계산기에 AND, OR, IFERROR를 더한다.
- 문안은 견본(12·13)을 먼저 승인받고 나머지(14~16)를 쓴다.

## 만드는 사람에게

- 문안은 `2026-11-21-excel-advanced-copy.md`(한국어)와 영어 파일을 테스트로 대조한다. 기본 문안 파일과 같은 형식.
- 빈칸 문제는 칩을 넣은 수식의 값으로 채점하므로, 오답 칩은 모두 정답과 **다른 값**을 내야 한다(테스트로 확인).
