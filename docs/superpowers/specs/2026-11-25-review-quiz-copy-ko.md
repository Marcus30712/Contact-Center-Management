## 퀴즈 1. 팀장 복습 퀴즈

### 문제 1

| 항목 | 한국어 |
|---|---|
| 질문 | 정식 팀에 온 지민의 평균 처리 시간(AHT)이 팀 평균보다 깁니다. FCR과 QA 정확도는 높습니다. 부매니저가 AHT를 줄이라고 합니다. 먼저 할 일은 무엇일까요? |
| 보기 a (오답) | AHT를 팀 평균까지 줄이는 목표로 바로 성과 개선 계획(PIP)을 시작한다. |
| a 피드백 | PIP는 코칭으로 부족할 때 쓰는 공식 절차입니다. 숫자 하나로 시작하면 지민이 잘하는 한 번에 해결하는 힘까지 흔들립니다. |
| 보기 b (정답) | 녹취와 지표를 함께 보고, 1:1에서 잘한 점과 줄일 구간을 찾는다. |
| 보기 c (오답) | 팀 허들에서 AHT 목표를 다시 알리고, 통화를 더 빨리 끝내자고 공지한다. |
| c 피드백 | 시간만 강조하면 상담사는 정확히 안내하는 법보다 빨리 끊는 법을 배웁니다. |
| 해설 | 한 지표만 보면 다른 지표를 희생시키는 코칭이 됩니다. 여러 지표와 실제 상담을 함께 보고, 1:1 코칭에서 행동을 정합니다. |
| 관련 레슨 | 라이프사이클 레슨 4 · 성과 관리 및 코칭 (../agent-lifecycle/#coaching-0) · 팀장 SOP · 1:1 코칭 (../sop-library/#coaching-0) |

### 문제 2

| 항목 | 한국어 |
|---|---|
| 질문 | 1:1 코칭을 세 번 했지만 지민의 같은 확인 단계 누락이 계속됩니다. 다음으로 할 일은 무엇일까요? |
| 보기 a (오답) | 방식은 그대로 두고, 같은 내용으로 한 번 더 1:1 코칭을 잡는다. |
| a 피드백 | 같은 방식이 세 번 통하지 않았다면, 목표와 지원을 공식적으로 정할 때입니다. |
| 보기 b (오답) | 세 번의 기회에도 나아질 기미가 없다며, 퇴사를 권한다. |
| b 피드백 | 공식적인 목표와 지원 없이 끝내면 팀원들은 도움을 청해도 소용없다고 느낍니다. |
| 보기 c (정답) | 데이터로 면담하고, 목표와 지원을 정해 매주 점검하는 PIP로 넘어간다. |
| 해설 | 코칭만으로 부족하면 PIP로 넘어갑니다. PIP는 벌이 아니라, 목표와 지원과 점검을 분명히 하는 절차입니다. |
| 관련 레슨 | 팀장 SOP · 성과 개선 계획 (PIP) (../sop-library/#pip-0) · 팀장 SOP · 1:1 코칭 (../sop-library/#coaching-0) |

| b 피드백 | 충격이 그대로 다음 고객에게 이어지고, 상담사는 보호받지 못했다고 느낍니다. |

| 해설 | 사람을 먼저 보호하고, 몰리는 불만은 부매니저나 매니저에게 바로 알려 여러 팀이 함께 움직이게 합니다. |
