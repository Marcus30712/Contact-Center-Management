# 등장인물 줄 · 본문 직급 표시 · 영어 "TL" — 설계

작성일: 2026-11-28 · 상태: 초안 (사용자 검토 대기) · 목업: 대화에서 승인받은 a·c·d·e·f·g·h·i·j 화면

## 왜

본문에 이름만 나오면 학습자가 그 사람이 누구인지(어떤 직급인지) 잊는다. 사용자 요청: 레슨 위에 등장인물을 "이름 (직급)"으로 보여 주고, 본문에서는 이름 대신 같은 색의 직급 표시를 쓴다.

## 결정된 것 (사용자 승인)

1. **등장인물 줄**: 레슨 제목·부제 아래, 그림 위. "**이름** (직급)" 알약 모양, 직급별 같은 색 테두리와 옅은 채우기, 이니셜 없음. 글자는 상하좌우 가운데. 단계 화면과 체크포인트 화면 모두. 사람이 많으면 다음 줄로 넘어가고 모두 보여 준다(접기 없음).
2. **본문 직급 표시**: 스텝·체크포인트 문제·보기·피드백·해설·다음 레슨 연결에서 이름 자리에 직급 알약을 쓴다. 조사는 직급에 맞춘다(하린은 → `직무전문가`는, 민석이 → `부매니저`가). 같은 레슨에 같은 직급이 둘 이상 나오면 그 직급은 이름을 함께 쓴다(`태오 팀장`, 영어 `TL Taeo`). 알약과 뒤따르는 조사는 줄바꿈으로 갈라지지 않는다.
3. **영어**: 본문(문장)에서는 "team leader" → "TL". 제목·부제·홈 카드·버튼·용어집처럼 이름표 자리는 어디서든 "Team Leader"(앞 글자 대문자). 등장인물 줄은 "Sujin (TL)". 본문 직급 알약 앞에는 문장에 맞게 "the"를 둔다("Give the `SME` …", 문장 첫머리 "The `AM` …").
4. **사람과 직급·색** (공통 파일 하나):

| 이름 | 한국어 | English | 색 |
|---|---|---|---|
| 지민, 서준 | 상담사 | Agent | 청록 |
| 준호 | 선임 상담사 | Senior agent | 청록 |
| 하린 | 직무전문가 | SME | 주황 |
| 도현 | 품질전문가 | QA | 보라 |
| 유나 | 트레이너 | Trainer | 보라 |
| 수진, 유키, 태오 | 팀장 | TL | 파랑 |
| 민석 | 부매니저 | AM | 분홍 |
| 정은 | 매니저 | Manager | 노랑 |

미소와 "당신"은 넣지 않는다.

## 방식

- **표시할 때 바꾼다.** 문안 문서와 레슨 파일의 문장은 지금처럼 이름으로 둔다(이야기 흐름이 그대로 남고, 문서-코드 비교 테스트도 그대로). 레슨 화면이 글을 그릴 때 이름을 찾아 직급 알약으로 바꾸고 조사를 고친다. 등장인물 줄도 그 레슨 글에 나온 이름에서 자동으로 만든다.
- 이름 바로 뒤에 같은 직급 말이 붙은 경우("수진 팀장", "Harin the SME", "Team Leader Sujin")는 직급 말까지 하나의 알약으로 바꾼다.
- **따옴표 안**(상담사가 하는 말 등, 약 16곳)은 이름을 그대로 둔다. 실제 대화에서는 이름을 부르기 때문이다.
- 낱말 속에 이름 글자가 들어 있는 경우("결정은")는 사람으로 세지 않는다.
- 화면 읽기 기능에는 알약 글자 그대로(직급) 읽힌다.
- 적용 범위: 같은 레슨 화면을 쓰는 강의 12개 전체(첫걸음 4, 라이프사이클 3, SOP 4, 커리어 1).
- 영어 "TL"/"Team Leader"는 표시 때가 아니라 **문안 자체를 고친다**(문서와 코드 함께): 본문 문장 약 330곳, 제목·부제 21곳, 그 밖의 이름표 자리.

## 하지 않는 것

- 길잡이, Codex, 복습 퀴즈, 용어집에는 등장인물 줄과 직급 알약을 넣지 않는다(영어 TL/Team Leader 표기만 맞춘다).
- 이름을 눌렀을 때의 동작은 이번에 넣지 않는다.

## 확인 방법

- 단위 테스트: 레슨마다 등장인물 줄 = 그 레슨 글에 나온 사람(직급 순서), "결정은" 같은 오검출 없음, 조사 바꿈 규칙(은/는, 이/가, 을/를, 과/와, 으로/로), 같은 직급 두 명일 때 이름 포함, 따옴표 안은 그대로, 영어 "the" 처리.
- 전체 레슨의 바뀐 문장을 한 파일로 뽑아 사람이 읽어 보는 검토(한국어·영어). 어색한 문장은 규칙을 고치거나 해당 문장만 예외로 둔다.
- 브라우저: 320px에서 알약이 넘치지 않음, 영어 화면에 한국어 없음, 체크포인트 화면에도 줄이 보임.
