# 체크포인트 보기 순서 섞기, 잠긴 연습의 시작 링크 (2026-11-26) — 짧은 설계

## 왜
- 상담사·직무전문가·팀장 강의 6개의 체크포인트 80문항은 정답이 모두 b입니다. 위치만 보고 맞힐 수 있습니다.
- 오늘의 연습이 잠겨 있을 때 나오는 링크는 직급과 상관없이 팀장용 "상담사 라이프사이클" 레슨 1로 갑니다.

## 정한 것 (사용자 승인, A안)
- 문안은 그대로 두고, 화면에 그릴 때 보기 순서를 문제마다 섞습니다.
  - 문제 id와 한국어 질문으로 순서를 정합니다. 같은 문제는 레슨, 오늘의 연습, 복습 퀴즈, 다시 방문했을 때 모두 같은 순서입니다.
  - 미소의 엑셀 연습은 이미 같은 방식으로 섞고 있어 그대로 둡니다.
- 잠긴 오늘의 연습의 링크는 그 직급의 첫 강의 레슨 1로 갑니다.
  - 상담사 → 상담사 첫걸음
  - 직무전문가 → 직무전문가 첫걸음
  - 팀장 → 팀장 첫걸음
  - 부매니저·매니저 → 미소의 엑셀 연습
  - 문구는 "{강의} 레슨 1 시작하기 →" / "Start {course} lesson 1 →"입니다.

## 만드는 방식
- `shared/option-order.js`의 `orderedOptions(q)`를 레슨 화면, 오늘의 연습, 복습 퀴즈가 함께 씁니다.

## 확인
- 테스트
  - 모든 보기가 그대로 있고 순서가 매번 같음
  - 직급 강의와 복습 퀴즈 143문항에서 정답이 세 자리에 고르게 퍼짐(각 25~42%)
  - 레슨과 오늘의 연습이 같은 순서
  - 직급별 잠긴 링크
- 브라우저 점검
