# 한국어 직급 이름 통일 (2026-11-26) — 짧은 설계

## 왜
한국어 모드에서 직급을 "SME", "TL"처럼 영어 약칭으로 부르면, 고른 언어와 표기가 달라 헷갈릴 수 있습니다(사용자). 상담사·팀장·부매니저·매니저처럼 SME도 한글 이름 "직무전문가"로 부릅니다.

## 정한 것 (사용자 승인)
- 직급 이름은 한 가지 형식으로 씁니다. 상단 선택 상자, 설정, 첫 방문 질문 창이 같은 이름을 씁니다.

  | 역할 | 한국어 모드 | 영어 모드 |
  |---|---|---|
  | agent | 상담사 / Agent | Agent |
  | sme | 직무전문가 / SME | Subject Matter Expert / SME |
  | tl | 팀장 / TL | Team Lead / TL |
  | am | 부매니저 / AM | Assistant Manager / AM |
  | om | 매니저 / OM | Operation Manager / OM |

- **B안:** 한국어 문구의 직급 약칭은 본문과 제목 모두 한글로 바꿉니다.
  - SME → 직무전문가
  - TL → 팀장
  - AM → 부매니저
  - OM → 매니저
- 영어 문구는 그대로 둡니다. "SME", "TL First Steps" 등이 해당합니다.

## 바뀌는 이름 (한국어)

| 지금 | 바뀐 뒤 |
|---|---|
| TL 첫걸음 | 팀장 첫걸음 |
| TL 서포트 라이프사이클 | 팀장 서포트 라이프사이클 |
| TL SOP 라이브러리 (링크 이름 "TL SOP · …") | 팀장 SOP 라이브러리 ("팀장 SOP · …") |
| TL 상황별 길잡이 | 팀장 상황별 길잡이 |
| SME 첫걸음 | 직무전문가 첫걸음 |
| SME 서포트 라이프사이클 | 직무전문가 서포트 라이프사이클 |
| SME SOP 라이브러리 | 직무전문가 SOP 라이브러리 |
| SME 상황별 길잡이 | 직무전문가 상황별 길잡이 |
| SME 하린, SME가 된 첫날 … | 직무전문가 하린, 직무전문가가 된 첫날 … |
| AM·OM에게 방침 받기 | 부매니저·매니저에게 방침 받기 |
| 준비 중 카드 "AM 첫걸음", "OM SOP 라이브러리" | "부매니저 첫걸음", "매니저 SOP 라이브러리" (짧은 이름 `ROLE_SHORT` 변경) |
| 용어집 SME의 한국어 이름 "분야 전문가" | "직무전문가" |
| Codex 커리어 매트릭스 "SME (Subject Matter Expert)" | "직무전문가 (SME)" (용어집의 "팀장 (TL)"과 같은 형식) |

## 규칙
- 한국어 문자열 안의 약칭만 바꿉니다. 영어 문자열, 코드 이름(`sme-lifecycle`, `SME_FIGURE` 등), 주소는 그대로 둡니다.
- 약칭이 그대로 남는 곳은 두 군데입니다.
  - 직급 이름 표기("직무전문가 / SME")
  - 한글 이름 뒤 괄호 속 약칭("팀장 (TL)"). 용어집 항목 이름 "SME", "Team Lead"도 그대로입니다.
- 조사를 맞춥니다.
  - SME → 직무전문가: 둘 다 모음으로 끝나 조사가 그대로입니다.
  - TL → 팀장: 받침이 있는 그대로이고, "TL로"만 "팀장으로"가 됩니다.
  - AM → 부매니저, OM → 매니저: 받침이 사라지므로 조사가 바뀝니다. 이→가, 은→는, 을→를, 과→와, 이나→나.
- 문안 문서는 테스트가 읽는 것만 같이 고칩니다. 테스트가 읽지 않는 옛 기록 문서는 그대로 둡니다. 이 문서와 상단 직급 선택 설계처럼 이름 자체를 적은 설계 문서도 그대로 둡니다.

## 접근 방식
- 고른 안: 한국어 문자열 안에서만 바꾸는 일회용 변환 스크립트를 씁니다. 바꾼 뒤 남은 약칭은 테스트로 막습니다.
- 버린 안: 직급 이름을 변수로 빼서 문구마다 끼워 넣기. 레슨 문안이 수백 곳이라 승인된 문안을 모두 다시 써야 합니다.

## 확인
- 새 테스트
  - 한국어 화면 문자열에 SME/TL/AM/OM 약칭이 남지 않음(위 예외 제외)
  - 직급 이름 표
  - 받침이 바뀌는 조사의 잘못된 조합이 없음(예: "매니저이", "부매니저은")
- 기존 문안 대조 테스트와 전체 테스트, 브라우저 점검
