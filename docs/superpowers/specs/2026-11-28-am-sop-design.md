# 부매니저 SOP 라이브러리 — 설계 (짧은 설계)

작성일: 2026-11-28 · 상태: 승인 (2026-11-28) · 문안: `2026-11-28-am-sop-copy-ko.md`

## 목적

부매니저 첫걸음(`am/`)이 역할이 바뀌는 첫 몇 달의 판단을 다룬다면, 이 강의는 부매니저가 매주·매달 되풀이하는 표준 절차 8개를 순서대로 다룹니다. 홈의 부매니저 역할에서 "곧 나와요"로 표시된 SOP 카드를 실제 강의로 바꿉니다.

## 하지 않는 것

- 손익과 계약의 결정 절차는 넣지 않습니다. 매니저 강의의 몫입니다. 인력 계획, SLA 관리, 위기 대응은 매니저 부재 때 미리 정한 범위 안에서 대행하는 부분만 다룹니다(레슨 8).
- 팀장·직무전문가 SOP와 같은 절차를 다시 가르치지 않습니다. 부매니저가 맡는 부분만 다룹니다.

## 방식

상담사 SOP 라이브러리(`agent-sop/`)와 같은 구조를 그대로 씁니다. 다른 방식은 검토하지 않았습니다. 이미 SOP 강의 세 개가 같은 구조로 돌아가고 있고, 진도·백업·복습·홈 연결이 그 구조를 기대하기 때문입니다.

- 폴더 `am-sop/` (ui.js, app.js, home.js, index.html, lessons 01~08)
- 진도 키 `am-sop:v1`, 내보내기 `AMS_UI`, `AMS_LESSONS`
- `ROLE_COURSES.am = ['am', 'am-sop']`, 홈 부매니저 SOP 카드를 실제 강의로
- 설정 백업·초기화 키, 서비스 워커 목록, 앱바, README, 개인정보 안내에 추가
- 등장인물 민석(인물 표시), 레슨 8개 · 체크포인트 2문제씩, 영어 문안은 한국어 승인 뒤 작성

## 레슨 8개

1. 팀장 주간 성과 미팅
2. 지침 전달과 확인 보고
3. 에스컬레이션 보고 점검
4. 리스크 관리 대장
5. 비즈니스 리뷰 자료 준비
6. 고객사 요청 정보 취합
7. 팀장 휴가와 백업 지정
8. 매니저 대행 인수인계

## 확인 방법

- 문안 문서와 코드가 글자 그대로 같은지 비교하는 테스트 (`am-sop.test.js`)
- 정답 단서 검사(`answer-length.test.js`)에 새 강의 포함
- 전체 테스트(`npm test`)와 브라우저 검사(`browser_check.py`) 통과
