## 레슨 1. 상담사 지원

| 항목 | 한국어 |
|---|---|
| 제목 | 상담사 지원 |
| 짧은 이름 | 상담사 |
| 부제 | 기대를 분명히 하고, 정기적으로 듣고, 막힐 때 개입합니다. |
| 노드 | 맡기기 · 받기 · 돕기 · 개입하기 |

스텝:

1. 이 레슨의 목적은 팀장이 상담사를 지원하는 절차를 맡기기, 받기, 돕기, 개입하기 네 단계로 보는 것입니다. 상담사 한 사람의 성장 과정은 상담사 라이프사이클이 다루고, 여기서는 매주 반복되는 지원을 봅니다.
2. 첫 단계는 맡기기입니다. 지민에게 기대하는 목표와 역할을 분명히 말합니다. 무엇이 잘한 것인지 모르면 상담사는 스스로 방향을 잡을 수 없습니다.
3. 둘째 단계는 받기입니다. 상담사에게서 받는 것은 숫자만이 아닙니다. 고객이 자주 묻는 것, 일하기 불편한 점 같은 현장의 이야기를 정기적인 1:1(예시: 매주 평가 리뷰 때)로 듣습니다.
4. 셋째 단계는 돕기입니다. 코칭, 칭찬, 필요한 도구와 자료를 줍니다. 서준처럼 합류한 지 얼마 안 된 사람에게는 직무전문가와 함께 더 가까이 붙습니다.
5. 잘하는 사람도 지원이 필요합니다. 지민처럼 오래 일한 사람에게는 새 업무나 버디 역할로 성장할 기회를 줍니다.
6. 넷째 단계는 개입하기입니다. 같은 문제가 반복되거나 근태나 행동에 문제가 있으면 팀장이 직접 나섭니다. 성과 문제가 코칭으로 풀리지 않으면 성과 개선 계획(PIP)을, 근태나 행동 문제는 센터의 근태 규정과 인사 절차를 따릅니다.
7. 개입은 빠를수록 작게 끝납니다. 몇 주 미루면 작은 습관이 큰 문제가 됩니다.
8. 모든 상담사를 같은 방식으로 돕지 않습니다. 팀장 첫걸음에서 만든 개인 메모가 누구에게 무엇이 필요한지 알려 줍니다.

체크포인트:

| 항목 | 한국어 |
|---|---|
| 1번 질문 | 서준이 이번 주 처리 목표를 몰랐다고 말합니다. 어느 단계가 빠졌을까요? |
| 보기 a (오답) | 돕기: 목표를 따라갈 수 있게 코칭이 충분하지 않았다. |
| a 피드백 | 코칭 전에, 무엇을 기대하는지부터 전해졌어야 합니다. |
| 보기 b (정답) | 맡기기: 목표를 분명히 전하지 않았다. |
| 보기 c (오답) | 개입하기: 목표에 못 미칠 때 더 일찍 지적했어야 했다. |
| c 피드백 | 목표를 모르는 사람에게 지적은 소용이 없습니다. 먼저 목표를 알려야 합니다. |
| 해설 | 지원은 기대를 분명히 하는 데서 시작합니다. |
| 2번 질문 | 지민의 같은 실수가 코칭 뒤에도 몇 주째 반복됩니다. 알맞은 것은 무엇일까요? |
| 보기 a (오답) | 오래 일한 지민이 스스로 고치기를 몇 주 더 기다린다. |
| a 피드백 | 미룰수록 작은 습관이 큰 문제가 되고, 개입은 더 어려워집니다. |
| 보기 b (정답) | 직접 개입해 원인을 보고, 계속되면 PIP를 검토한다. |
| 보기 c (오답) | 지민을 매일 보는 직무전문가에게 실수 관리를 맡긴다. |
| c 피드백 | 반복되는 성과 문제의 관리는 팀장의 몫입니다. 직무전문가는 업무를 돕지만 평가하거나 조치하지 않습니다. |
| 해설 | 코칭으로 풀리지 않는 반복 문제는 팀장이 직접 개입합니다. |
| 다음 레슨 연결 | 상담사를 가장 가까이에서 돕는 사람은 직무전문가입니다. 다음은 팀장이 직무전문가를 지원하는 법입니다. |

## 레슨 2. 직무전문가 지원

| 항목 | 한국어 |
|---|---|
| 제목 | 직무전문가 지원 |
| 짧은 이름 | 직무전문가 |
| 부제 | 승인 권한과 대신 맡길 일을 정하고, 현장의 트렌드를 받습니다. |
| 노드 | 맡기기 · 받기 · 돕기 · 개입하기 |

스텝:

1. 이 레슨의 목적은 팀장이 직무전문가를 지원하는 절차를 팀장 쪽에서 보는 것입니다.
2. 첫 단계는 맡기기입니다. 직무전문가 하린과 승인 권한 목록을 맞추고, 출석 관리나 허들처럼 대신 맡길 일을 정합니다. 권한이 분명해야 하린이 매번 묻지 않고 판단할 수 있습니다.
3. 둘째 단계는 받기입니다. 하린에게서 주간 트렌드 요약, 출석 결과, 팀원별 단계 현황을 정해진 날에 받습니다. 받은 요약은 그 주의 코칭 계획에 바로 씁니다.
4. 셋째 단계는 돕기입니다. 직무전문가는 요청이 몰리면 혼자 버티기 쉽습니다. 바쁜 시간대에는 팀장이 함께 서포트하거나 RTA와 인원을 조정합니다.
5. 직무전문가의 성장도 돕습니다. 하린이 팀장 자리를 바란다면 회의 진행이나 신입 계획 같은 일을 조금씩 맡겨 봅니다.
6. 넷째 단계는 개입하기입니다. 근태, 성과 조치, 정책 밖 승인처럼 직무전문가가 넘긴 일은 팀장이 직접 결정합니다. 승인 판단의 결과는 하린에게도 알려 같은 일이 다시 생기면 어떻게 할지 알게 하고, 근태나 성과 조치의 내용은 당사자, 꼭 필요한 사람(부매니저, 인사 담당)과만 다룹니다.
7. 직무전문가를 작은 팀장으로 쓰지 않습니다. 평가와 조치까지 넘기면 직무전문가와 상담사의 관계가 무너집니다.

체크포인트:

| 항목 | 한국어 |
|---|---|
| 1번 질문 | 하린이 비슷한 보상 요청마다 팀장에게 묻습니다. 먼저 할 일은 무엇일까요? |
| 보기 a (오답) | 매번 바로 답해 준다. |
| a 피드백 | 매번 답하면 팀장의 하루가 막히고, 하린은 스스로 판단할 기준을 얻지 못합니다. |
| 보기 b (정답) | 같은 요청이 반복되니, 하린과 승인 권한 목록을 다시 맞춘다. |
| 보기 c (오답) | 하린을 믿고, 앞으로는 보상 요청을 모두 알아서 판단하라고 한다. |
| c 피드백 | 기준 없이 맡기면 요청마다 다르게 승인하게 됩니다. |
| 해설 | 권한을 분명히 맡겨야 직무전문가가 같은 기준으로 판단합니다. |
| 2번 질문 | 하린이 한 상담사의 반복되는 지각을 알려 왔습니다. 알맞은 것은 무엇일까요? |
| 보기 a (오답) | 상황을 가장 잘 아는 하린에게, 그 상담사에게 직접 경고하라고 한다. |
| a 피드백 | 근태 조치는 팀장의 몫입니다. 직무전문가에게 넘기면 상담사와의 관계가 무너집니다. |
| 보기 b (정답) | 직접 확인해 조치하고, 하린에게는 처리했다는 것만 알린다. |
| 보기 c (오답) | 하린의 보고이니 따로 확인하지 않고 바로 조치한다. |
| c 피드백 | 팀장이 직접 사실을 확인해야 공정한 조치가 됩니다. |
| 해설 | 넘겨받은 일은 팀장이 직접 확인하고 결정합니다. |
| 다음 레슨 연결 | 직무전문가가 현장을 돕는다면, QA는 품질의 기준을 지킵니다. 다음은 QA와 일하는 법입니다. |

## 레슨 3. QA 지원

| 항목 | 한국어 |
|---|---|
| 제목 | QA 지원 |
| 짧은 이름 | QA |
| 부제 | 평가 기준을 함께 맞추고, 품질 결과를 코칭으로 바꿉니다. |
| 노드 | 맡기기 · 받기 · 돕기 · 개입하기 |

스텝:

1. 이 레슨의 목적은 팀장이 QA와 함께 일하며 품질 평가를 팀의 성장으로 이어 가는 절차를 보는 것입니다.
2. 첫 단계는 맡기기입니다. QA 도현에게 팀에서 특히 봐 줬으면 하는 부분을 요청합니다. 예를 들어 새 정책이 시작된 주에는 관련 문의를 더 많이 평가해 달라고 부탁합니다.
3. 둘째 단계는 받기입니다. 팀원별 품질 점수와 자주 감점된 항목을 정해진 주기(예시: 매주)로 받습니다. 점수만이 아니라 감점 이유와 녹취 사례까지 받아야 코칭에 쓸 수 있습니다.
4. 셋째 단계는 돕기입니다. 캘리브레이션에 참여해 현장 사정과 팀장의 시각을 전합니다. 기준이 바뀌면 팀에 먼저 알려, 상담사가 모르는 기준으로 평가받지 않게 합니다.
5. 상담사가 평가에 이의를 제기하면, 팀장이 먼저 녹취를 함께 듣고 근거가 있을 때 정해진 절차로 다시 검토를 요청합니다. QA와 상담사가 직접 다투게 두지 않습니다.
6. 넷째 단계는 개입하기입니다. 팀의 품질이 계속 떨어지거나 평가가 사람마다 다르다는 말이 나오면, 팀장이 QA와 따로 만나 원인을 함께 봅니다.
7. QA는 상대 팀이 아니라 같은 목표를 가진 동료입니다. 점수를 두고 다투기보다 같은 녹취를 함께 듣는 시간이 더 많은 것을 바꿉니다.

체크포인트:

| 항목 | 한국어 |
|---|---|
| 1번 질문 | 도현에게서 품질 점수만 받고 있습니다. 코칭에 쓰려면 무엇을 더 받아야 할까요? |
| 보기 a (오답) | 팀 순위표 (누가 가장 낮은지 바로 보이게) |
| a 피드백 | 순위는 누가 낮은지만 알려 줄 뿐, 무엇을 코칭할지는 알려 주지 않습니다. |
| 보기 b (정답) | 자주 감점된 항목과 그 녹취 사례 |
| 보기 c (오답) | 평가한 사람의 이름 |
| c 피드백 | 누가 평가했는지보다 무엇이 왜 감점됐는지가 코칭에 필요합니다. |
| 해설 | 감점 이유와 사례가 있어야 점수가 코칭으로 바뀝니다. |
| 2번 질문 | 서준이 QA 점수가 부당하다며 이의를 제기합니다. 알맞은 것은 무엇일까요? |
| 보기 a (오답) | 점수는 본인 일이니, 서준에게 QA를 직접 찾아가 따지라고 한다. |
| a 피드백 | 상담사와 QA가 직접 다투면 관계가 나빠지고 결론도 나기 어렵습니다. |
| 보기 b (정답) | 녹취를 함께 듣고, 근거가 있으면 절차대로 재검토를 요청한다. |
| 보기 c (오답) | 이번 QA 평가는 그대로 받아들이라고 다독인다. |
| c 피드백 | 근거 있는 이의를 막으면 상담사는 평가를 믿지 않게 됩니다. |
| 해설 | 이의는 팀장이 먼저 근거를 확인하고 절차대로 전합니다. |
| 다음 레슨 연결 | 품질의 기준을 맞췄다면, 그 기준을 처음 가르치는 사람은 트레이너입니다. 다음은 트레이너와 일하는 법입니다. |

## 레슨 4. 트레이너 지원

| 항목 | 한국어 |
|---|---|
| 제목 | 트레이너 지원 |
| 짧은 이름 | 트레이너 |
| 부제 | 현장에 필요한 교육을 요청하고, 교육 결과를 현장에서 이어 갑니다. |
| 노드 | 맡기기 · 받기 · 돕기 · 개입하기 |

스텝:

1. 이 레슨의 목적은 팀장이 트레이너와 함께 신입 교육과 추가 교육을 현장에 맞게 만들어 가는 절차를 보는 것입니다.
2. 첫 단계는 맡기기입니다. 트레이너 유나에게 팀에 필요한 교육을 근거와 함께 요청합니다. 예를 들어 "환불 문의 오안내가 이번 달 12건(예시)"처럼 사례를 붙이면 교육의 목표가 분명해집니다.
3. 둘째 단계는 받기입니다. 신입의 교육 기록, 실무 체험에서 더 볼 유형, 수료 평가를 유나에게 받아 직무전문가와 함께 나눕니다.
4. 셋째 단계는 돕기입니다. 교육 자료와 현장 방식이 다르면 알려 주고, 교육에 쓸 실제 사례와 녹취를 찾아 줍니다. 현장에서 온 사례가 교육을 살아 있게 합니다.
5. 교육이 끝난 뒤가 더 중요합니다. 배운 것이 현장에서 쓰이는지 직무전문가와 함께 확인하고, 결과를 유나에게 다시 알려 줍니다.
6. 넷째 단계는 개입하기입니다. 준비가 덜 된 신입이 있으면, 유나와 함께 수료를 미루고, 실무 체험 기간을 늘릴지 추가 교육을 할지 정합니다. 인원이 급하다고 무리하게 투입하지 않습니다.
7. 트레이너는 교실 안을, 팀장은 현장을 책임집니다. 두 사람이 같은 신입을 같은 눈으로 볼 때 신입이 오래 남습니다.

체크포인트:

| 항목 | 한국어 |
|---|---|
| 1번 질문 | 트레이너에게 추가 교육을 요청할 때 알맞은 것은 무엇일까요? |
| 보기 a (오답) | "요즘 팀이 전반적으로 약해요. 기본 교육을 한 번 더 부탁드려요." |
| a 피드백 | 무엇이 약한지 모르면 트레이너는 교육의 목표를 정할 수 없습니다. |
| 보기 b (정답) | "환불 오안내가 이번 달 12건(예시)이에요. 사례를 첨부합니다." |
| 보기 c (오답) | "다음 기수 교육을 늘려 주세요. 신입이 같은 문제를 겪지 않게요." |
| c 피드백 | 지금 팀원의 문제를 다음 기수 교육으로는 풀 수 없습니다. |
| 해설 | 교육 요청은 무엇을 왜 배워야 하는지 사례와 함께 합니다. |
| 2번 질문 | 인원이 부족한데 수료를 앞둔 신입 한 명이 아직 준비가 덜 됐습니다. 어떻게 할까요? |
| 보기 a (오답) | 예정대로 수료시켜 바로 정식 팀에 투입한다. |
| a 피드백 | 준비가 덜 된 채 투입하면 고객과 신입 모두 힘들어지고, 신입이 떠나기 쉽습니다. |
| 보기 b (정답) | 트레이너와 함께 수료를 미루고, 실무 체험 연장이나 추가 교육을 정한다. |
| 보기 c (오답) | 신입에게 자료를 주고, 수료 전까지 혼자 더 공부하라고 한다. |
| c 피드백 | 혼자 두면 같은 곳에서 계속 막히고, 무엇이 부족한지도 모른 채 시간이 갑니다. |
| 해설 | 준비가 덜 된 신입은 트레이너와 함께 준비시킨 뒤 투입합니다. |
| 다음 레슨 연결 | 상담사, 직무전문가, QA, 트레이너를 각각 보았습니다. 마지막은 이들을 한 팀으로 묶는 일입니다. |

## 레슨 5. 팀 전체 지원

| 항목 | 한국어 |
|---|---|
| 제목 | 팀 전체 지원 |
| 짧은 이름 | 팀 전체 |
| 부제 | 허들과 팀 회의로 같은 목표를 보게 하고, 역할 사이를 잇습니다. |
| 노드 | 맡기기 · 받기 · 돕기 · 개입하기 |

스텝:

1. 이 레슨의 목적은 상담사, 직무전문가, QA, 트레이너가 따로 움직이지 않고 한 팀으로 같은 목표를 보도록 팀장이 잇는 절차를 보는 것입니다.
2. 첫 단계는 맡기기입니다. 팀 목표를 모두가 아는 말로 정하고, 각 역할이 그 목표에 어떻게 기여하는지 알려 줍니다.
3. 둘째 단계는 받기입니다. 정기적인 팀 회의(예시: 주 1회)에서 직무전문가, QA, 트레이너가 본 것을 함께 나눕니다. 따로 들으면 놓치는 연결이 한자리에서 보입니다.
4. 예를 들어 하린은 환불 문의가 늘었다고 하고, 도현은 환불 안내 감점이 늘었다고 하고, 유나는 환불 교육이 지난 정책 기준이라고 말합니다. 세 사람의 이야기가 한 원인을 가리킵니다.
5. 셋째 단계는 돕기입니다. 매일 허들에서 오늘의 우선순위와 바뀐 정책을 짧게 전하고, 잘한 사람과 잘한 일을 구체적으로 칭찬합니다.
6. 넷째 단계는 개입하기입니다. 상담사와 QA가 평가를 두고 부딪히는 것처럼 역할 사이에 갈등이 생기면, 팀장이 양쪽 이야기를 듣고 QA와 캘리브레이션으로 기준을 다시 맞춥니다.
7. 팀의 결과는 정해진 주기로 부매니저에게 보고하고, 받은 방침을 다시 팀 목표로 바꿔 전합니다. 팀장은 위와 아래를 잇는 자리입니다.
8. 이렇게 한 바퀴를 돌면 다시 한 사람씩 볼 차례입니다. 팀 전체에서 보인 것이 다음 상담사 지원의 출발점이 됩니다.

| 항목 | 한국어 |

| 1번 질문 | 직무전문가, QA, 트레이너가 각각 다른 문제를 이야기합니다. 팀장이 먼저 할 일은 무엇일까요? |
