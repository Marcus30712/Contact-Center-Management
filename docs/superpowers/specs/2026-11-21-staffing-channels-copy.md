## 입력값

| 키 | 라벨 | 한 줄 설명 |
|---|---|---|
| planned | (다시 씀) 계획된 Shrinkage | (다시 씀) 휴식, 교육, 회의처럼 미리 계획된 시간입니다. |
| unplanned | (다시 씀) 계획되지 않은 Shrinkage | (다시 씀) 결근, 지각, 병가처럼 계획되지 않은 시간입니다. |
| weeklyHours | 1인 주간 근무 시간 | 상담사 한 명이 일주일에 근무하는 계약 시간입니다. |
| dailyVolume | 하루 문의량 | 하루 동안 들어오는 문의 수입니다. |
| aht (전화) | (다시 씀) 평균 처리 시간 (AHT) | (다시 씀) 문의 한 건을 처리하는 데 걸리는 평균 시간입니다. |
| aht (채팅) | (다시 씀) 평균 처리 시간 (AHT) | 대화 한 건이 시작부터 끝날 때까지 걸리는 평균 시간입니다. |
| aht (이메일) | (다시 씀) 평균 처리 시간 (AHT) | 이메일 한 건을 읽고 답장하는 데 걸리는 평균 시간입니다. |
| concurrency | 동시 처리 수 | 상담사 한 명이 한 번에 맡는 채팅 수입니다. |
| target (전화) | (다시 씀) 목표 응답 시간 | (다시 씀) 이 시간 안에 응답하는 것을 목표로 합니다. |
| target (채팅) | (다시 씀) 목표 응답 시간 | 고객의 첫 메시지에 이 시간 안에 응답하는 것을 목표로 합니다. |
| hoursOpen | 하루 운영 시간 | 이 채널에서 문의를 받는 하루 시간입니다. |
| daysOpen | 주 운영 일수 | 일주일에 이 채널을 운영하는 날 수입니다. |
| current | 지금 편성 인원 | 이 채널을 맡은 상담사 수입니다. |

단위: 시간 → "시간", 일수 → "일", 동시 처리 수 → "건". 나머지는 30분 연습과 같다(건, 분, 명, %, 초).
