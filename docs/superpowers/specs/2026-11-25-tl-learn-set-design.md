# TL 배우기 구성 변경 — 설계와 바뀌는 문구

작성일: 2026-11-25 · 상태: 설계 승인됨 (2026-11-25, 추천 옵션) · 문구: 최종 보고에서 승인 요청

## 1. 의도와 이유

SME 배우기와 같은 틀로 TL 배우기를 맞춘다. 새로 팀장이 된 사람이 팀을 운영하기 전에 팀원과 팀을 파악하는 법(TL 첫걸음)과, 팀장이 팀을 이루는 상담사·SME·QA·트레이너를 각각 지원하는 법(TL 서포트 라이프사이클)을 미리 배운다.

## 2. 결정 (사용자)

- TL 배우기: TL 첫걸음(새로) · 상담사 라이프사이클(유지) · TL 서포트 라이프사이클(새로) · TL SOP 라이브러리(이름 변경) · 미소의 엑셀 연습(유지).
- SME의 "서포트 라이프사이클"은 "SME 서포트 라이프사이클"로 이름을 바꾼다.
- TL 서포트 라이프사이클은 팀장이 팀 전체(상담사, SME, QA, 트레이너)를 지원하는 라이프사이클이고, 역할별로 나눈다(A안): 상담사 → SME → QA → 트레이너 → 팀 전체.
- TL 첫걸음은 사용자가 알려 준 신입 팀장의 첫 몇 주를 따른다: 팀원 파악(로스터) → 개인 성과(최근 6개월 기록) → 콜 레코딩·티켓 직접 보기 → 팀의 기여 → 팀원 한 명씩 다루는 법 → AM·OM에게 방침 받기. 이 파악에는 SME·QA·트레이너와의 협업이 필수다.
- 제안 승인: TL 첫걸음 레슨 6에 첫 1:1 면담, 인물은 지민·서준·준호와 새 AM 한 명.
- 진행: 추천 옵션으로 모두 진행하고, 모두 끝나면 커밋 전에 자세히 보고한 뒤 커밋 승인을 받는다.

## 3. 결정 (제작자, 추천 옵션)

- 새 폴더 `tl/`(TL 첫걸음, 목록 첫 화면)와 `tl-support/`(TL 서포트 라이프사이클, 원형 첫 화면). 진도 키 `tl-course:v1`, `tl-support:v1`.
- TL의 배우기·내 학습 순서: TL 첫걸음, 상담사 라이프사이클, TL 서포트 라이프사이클, TL SOP 라이브러리, 엑셀. 처음 안내는 TL 첫걸음 레슨 1을 가리킨다.
- TL 복습 퀴즈는 지금처럼 상담사 라이프사이클 + TL SOP로 열린다(SME 퀴즈를 SME 첫걸음에 묶어 둔 것과 같은 방식).
- 새 인물: SME 하린, QA 도현, 트레이너 유나, AM 민석 부매니저. 수진 팀장은 다른 강의에서 팀장이라 이 두 강의에는 나오지 않는다(당신 = 팀장).
- TL 길잡이는 그대로 둔다. 링크 이름의 "SOP · …"만 "TL SOP · …"로 바뀐다.
- 오늘의 연습, 백업, 학습 초기화, 아래 메뉴(배우기), 오프라인 목록에 두 강의를 넣는다.

## 4. 이름 변경으로 바뀌는 문구

| 위치 | 지금 | 바뀐 뒤 |
|---|---|---|
| SME 강의 제목 (홈 카드, 강의 화면, 내 학습) | 서포트 라이프사이클 / Support Lifecycle | SME 서포트 라이프사이클 / SME Support Lifecycle |
| SME 길잡이 링크 이름 | 서포트 라이프사이클 레슨 N · … | SME 서포트 라이프사이클 레슨 N · … |
| SME 서포트 라이프사이클 마지막 연결 | 서포트 라이프사이클을 마쳤습니다. … | SME 서포트 라이프사이클을 마쳤습니다. … |
| SME SOP 마지막 연결 | …서포트 라이프사이클에서 다시 볼 수 있습니다. | …SME 서포트 라이프사이클에서 다시 볼 수 있습니다. |
| TL SOP 강의 제목 (홈 카드, 강의 화면, 내 학습) | SOP 라이브러리 / SOP Library | TL SOP 라이브러리 / TL SOP Library |
| TL·SME 길잡이와 복습 퀴즈의 링크 이름 | SOP · … | TL SOP · … |
| TL 길잡이 s17 이어서 볼 곳, Codex 원페이저 다음 링크 | SOP 라이브러리 (· 1:1 코칭) | TL SOP 라이브러리 (· 1:1 코칭) |
| 용어집 카드 링크 | SOP 라이브러리에서 보기 | TL SOP 라이브러리에서 보기 |
| 복습 퀴즈 팀장 범위 | 상담사 라이프사이클 6개 + SOP 라이브러리 10개 | 상담사 라이프사이클 6개 + TL SOP 라이브러리 10개 |
| SME 첫걸음 마지막 연결 | …SOP 라이브러리의 스크러빙, … | …TL SOP 라이브러리의 스크러빙, … |
| 홈 처음 안내 (TL) | 처음이라면 라이프사이클 레슨 1부터 시작해 보세요. | 처음이라면 TL 첫걸음 레슨 1부터 시작해 보세요. |

바뀌지 않는 것: 배지 이름 "SOP 완주", Codex 본문의 "Master SOP 라이브러리", SME SOP 본문의 "팀장 SOP".

## 7. 성공 확인

- TL 홈의 배우기 카드 5개가 위 순서로 열리고, 내 학습에 같은 순서로 보인다. SME에게는 TL 강의가, TL에게는 SME 강의가 보이지 않는다.
- 두 새 강의를 끝까지 넘길 수 있고, 마친 레슨의 문제가 오늘의 연습에 나오며 연습의 링크가 그 강의로 간다.
- 이름이 바뀐 곳이 모두 새 이름을 쓰고, 테스트가 문안 문서와 같은지 확인한다.
- TL 복습 퀴즈는 상담사 라이프사이클 + TL SOP만으로 열린다.
- 전체 테스트와 브라우저 점검이 통과한다.
