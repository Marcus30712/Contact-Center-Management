# 학습 앱으로 묶기 — 1단계 "앱 껍데기" 설계 문서

작성일: 2026-11-20 · 상태: 검토 대기

## 0. 전체 그림과 이 문서의 범위

Knowledge Base를 Learning-Python처럼 휴대폰에서 앱처럼 쓰는 학습 앱으로 묶는다. 세 단계로 나누고, 단계마다 설계 문서를 따로 쓴다.

1. **1단계 — 앱 껍데기 (이 문서)**: 홈 화면 설치·오프라인, 첫 화면 "내 학습", 아래쪽 메뉴, 안내 캐릭터 김미소.
2. 2단계 — 매일 조금씩: 오늘의 3문제, 용어 플래시카드, 연속 기록, 배지. 미소의 표정이 정답·오답·완료에 반응.
3. 3단계 — 미소의 엑셀 연습장: 휴대폰 화면의 작은 표에서 수식 연습. 다룰 기능 목록은 그때 정한다.

## 1. 의도와 이유

신입 팀장이 **혼자, 휴대폰으로 틈틈이** 본다. 지금은 주제 7개가 따로 있는 웹 페이지 묶음이라, 어디까지 했는지 한눈에 보이지 않고 매번 브라우저 주소로 들어와야 한다. 1단계는 내용을 바꾸지 않고, 앱처럼 열고·이어서 하고·오프라인에서도 보이게 만든다.

## 2. 목표 · 비목표 · 반목표

**목표**
- 휴대폰 홈 화면에 추가하면 앱처럼 열린다 (이름, 아이콘, 주소창 없는 화면). 한 번 연 뒤에는 비행기 모드에서도 모든 주제가 열린다.
- 첫 화면에 김미소가 인사하고, "내 학습"에 라이프사이클 강의와 SOP 라이브러리의 진행률과 "이어서 할 레슨"이 보인다.
- 모든 화면 아래쪽에 같은 메뉴(홈 / 배우기 / 길잡이 / 찾아보기)가 있다.
- 레슨을 마치면 미소가 축하한다.
- 첫 화면도 다른 주제처럼 한국어/영어 버튼을 따른다 (지금은 두 언어를 함께 적어 둠).

**비목표**
- 2·3단계의 내용(오늘의 문제, 플래시카드, 연속 기록, 배지, 엑셀).
- 의상실, 상점, 포인트 — 비즈니스 교육용이라 넣지 않는다 (사용자 결정).
- 서버, 로그인, 기기 사이 진도 동기화. 진도는 지금처럼 휴대폰 안에만 저장한다.
- 한 화면짜리 앱으로 다시 짜기 (지금 페이지들을 그대로 둔다).

**반목표**
- 미소가 학습을 방해하는 것: 긴 대사, 자동으로 뜨는 말풍선, 소리. 미소는 첫 화면과 레슨 완료에만 짧게 나온다.
- 오프라인 저장 때문에 고친 내용이 휴대폰에 늦게 반영되는 것. 새 판이 나오면 다음 열 때 바로 새 내용을 쓴다.
- Learning-Python의 글·그림·이름(리아, 텃밭 등)을 가져오는 것. 구조와 방식만 참고한다.

## 3. 접근 방식

- **A. 지금 사이트에 앱 껍데기를 씌우기** — 페이지는 그대로, 설치·오프라인·내 학습·아래쪽 메뉴를 더한다. 빌드 단계 없음. **사용자 선택 (1단계).**
- B. 한 화면짜리 앱으로 다시 짜기 — 가장 앱답지만 7개 주제의 연결을 다시 만들고 빌드 단계가 생긴다. 필요하면 나중 단계.
- C. Learning-Python 엔진을 복사한 새 저장소 — 파이썬 채점 중심이라 맞지 않고 저장소가 나뉜다.

## 4. 결정된 사항

### 4.1 사용자 결정
- 쓰는 방식: 신입 팀장이 혼자, 휴대폰으로 틈틈이.
- 안내 캐릭터 **김미소 (Miso Kim)**: 신입 팀장을 돕는 선배 매니저(Operation Manager). 레슨 속 상담사 한지민과는 다른 인물.
- 이미지: 사용자가 Google Gemini로 만든 프로필 1장과 표정 시트 1장. 공개 저장소에 사용 가능.
- 표정 12개 이름과 쓰일 곳:

  | # | 이름 | 쓰일 곳 | # | 이름 | 쓰일 곳 |
  |---|---|---|---|---|---|
  | 1 | 미소 smile | 레슨 시작, 기본 | 7 | 활짝 grin | 첫 화면 인사 |
  | 2 | 기쁨 joy | 정답 | 8 | 뿌듯 proud | 레슨 완료 |
  | 3 | 반짝 sparkle | 배지·연속 기록 달성 | 9 | 갸웃 ponder | 확인 문제를 고민할 때 |
  | 4 | 생각 think | 힌트, 길잡이 | 10 | 난감 nervous | 오답 한 번 더 |
  | 5 | 놀람 surprise | 새 내용 열림 | 11 | 응원 cheer | 오늘의 문제 완료 |
  | 6 | 걱정 worry | 오답 | 12 | 윙크 wink | 팁, 엑셀 요령 |

  1단계에서 쓰는 것은 7 활짝(첫 화면), 8 뿌듯(레슨 완료), 4 생각(길잡이 첫머리)이다. 나머지는 2·3단계에서 쓴다.
- 의상실·상점 제거, "리아의 텃밭" 자리에 엑셀 연습(3단계).

### 4.2 제작자 결정 (검토하며 고칠 수 있음)

**이미지**
- 프로필과 표정 12개를 잘라 베이지 배경을 투명하게 만든다 (어두운 화면에서 네모가 보이지 않게). 원본은 `art/miso/`에 그대로 두고, 쓰는 파일은 `assets/miso/`에 WebP로 둔다 (`profile.webp`, `smile.webp` … `wink.webp`).
- 앱 아이콘은 프로필 얼굴 부분으로 만든다 (192px, 512px, 가장자리를 둥글게 잘라도 되는 "maskable" 판 포함).
- 이미지 출처는 README와 참고 자료 페이지에 "캐릭터 김미소 이미지: Marcus Shim이 Google Gemini로 생성"으로 적는다. 저장소 라이선스(MIT)를 그대로 따른다.
- 모든 미소 이미지에는 대체 글(예: "김미소, 활짝 웃는 얼굴")을 단다.

**첫 화면 (홈)**
```
┌ Contact Center KB ────────── 한국어|English ┐
│ [미소 활짝]  안녕하세요, 김미소예요.          │
│             오늘도 조금씩 같이 가 봐요.       │
│ 내 학습                                      │
│  상담사 라이프사이클  ███░░░ 3/6             │
│     이어서: 레슨 4 · 성과 관리 및 코칭 →     │
│  SOP 라이브러리      █░░░░░░ 1/7             │
│     이어서: 1:1 코칭 →                       │
│ 어디서부터 볼까요? · 팀장 상황별 길잡이 →    │
│ 배우기   (강의 2개)                          │
│ 찾아보기 (원페이저, 실험실, 용어집, 참고 자료)│
├──────────────────────────────────────────────┤
│   홈      배우기      길잡이      찾아보기   │
└──────────────────────────────────────────────┘
```
- 아직 아무것도 시작하지 않았으면 "내 학습" 대신 "처음이라면 라이프사이클 레슨 1부터" 안내를 보인다. 모두 마쳤으면 "다 마쳤어요" 표시와 다시 보기 링크.
- "이어서 할 레슨" = 순서상 아직 마치지 않은 첫 레슨.
- 첫 화면 글은 데이터 파일로 옮기고 한국어/영어 버튼을 붙인다.

**아래쪽 메뉴**
- 홈(`./`), 배우기(`./#learn`), 길잡이(`./guide/`), 찾아보기(`./#browse`). 지금 있는 곳은 강조한다.
- 모든 주제 페이지 아래에 같은 메뉴가 붙는다 (공통 파일 하나). 위쪽의 기존 막대(뒤로 가기, 언어 버튼)는 그대로 둔다.
- 휴대폰 아래 가장자리(홈 막대)와 겹치지 않게 여백을 둔다. 메뉴 높이만큼 페이지 아래 여백을 늘려 내용이 가려지지 않게 한다.

**레슨 완료의 미소**
- 라이프사이클과 SOP의 확인 문제를 다 풀면 나오는 "다음으로" 카드 위에 미소(뿌듯)와 한 줄 축하를 넣는다.

**설치와 오프라인**
- 앱 정보 파일(`manifest.webmanifest`): 이름 "Contact Center KB", 짧은 이름 "CC KB", 시작 주소 `./`, 테마 색은 사이트 강조색. (2026-11-20 이름 변경: 이름·짧은 이름 모두 "Miso Academy". 첫 화면 제목 "미소 아카데미" / "Miso Academy". LOG 20.)
- 오프라인 작업자(`sw.js`, 저장소 맨 위): 처음 설치될 때 모든 페이지·스크립트·스타일·미소 이미지를 미리 받아 둔다. Codex PDF(약 0.9MB)는 미리 받지 않고, 한 번 열면 그때 저장한다.
- 판 번호: 미리 받을 파일 목록과 판 번호를 담은 `sw.js`를 도구(`tools/sw_list.py`)로 다시 만든다. 테스트가 목록이 실제 파일과 같은지 확인한다 (파일을 더하고 목록을 잊으면 테스트 실패).
- 새 판: 판 번호가 바뀌면 새 작업자가 바로 이전 것을 대신하고, 다음에 열 때 새 내용이 보인다.
- 아이폰은 "공유 → 홈 화면에 추가"로 설치한다는 안내를 첫 화면 아래에 한 줄 둔다.

### 4.3 한국어 문안 초안 (승인 필요)
- 첫 화면 인사: "안녕하세요, 김미소예요. 오늘도 조금씩 같이 가 봐요."
- 미소 소개(인사 아래 작은 글씨): "신입 팀장을 돕는 선배 매니저"
- 내 학습 제목: "내 학습" · 이어서: "이어서:" · 처음: "처음이라면 라이프사이클 레슨 1부터 시작해 보세요." · 다 마침: "다 마쳤어요. 필요한 레슨은 언제든 다시 볼 수 있어요."
- 묶음 제목: "배우기" / "찾아보기"
- 아래쪽 메뉴: 홈 / 배우기 / 길잡이 / 찾아보기
- 레슨 완료 축하: "한 단계 마쳤어요. 오늘 배운 걸 팀에서 한 번 써 보세요."
- 설치 안내: "휴대폰 홈 화면에 추가하면 앱처럼 쓰고 오프라인에서도 볼 수 있어요. (아이폰: 공유 → 홈 화면에 추가)"
- 첫 화면 카드 설명은 지금 문구를 그대로 쓴다.

## 5. 만드는 방법 (제작자 선택)

- 새 파일: `shared/appbar.js`(아래쪽 메뉴, 모든 페이지가 불러 씀), `shared/appbar.css`, `home/`(첫 화면 데이터와 그리기: `data.js`, `render.js`, `app.js`), `assets/miso/*`, `art/miso/*`(원본), `manifest.webmanifest`, `sw.js`, `icons/*`, `tools/miso_cut.py`(이미지 자르기), `tools/sw_list.py`.
- 고치는 파일: 맨 위 `index.html`(첫 화면을 그리기 코드로), 각 주제의 `index.html`(메뉴와 작업자 등록 한 줄씩), 라이프사이클·SOP 레슨 화면의 완료 카드, README, LOG.md, 참고 자료(이미지 출처).
- 진도 읽기: 라이프사이클 `agent-lifecycle-course:v1`, SOP `sop-library:v1`를 그대로 읽는다 (저장 방식은 바꾸지 않는다).
- 테스트: 내 학습 계산(처음 / 중간 / 다 마침 / 저장소 막힘), 첫 화면 한국어·영어, 메뉴의 현재 위치, 작업자 목록 = 실제 파일, 앱 정보 파일 필수 항목, 미소 이미지 12+1개와 대체 글. 브라우저 점검: 모든 주제에 메뉴가 보이고 내용을 가리지 않음, 첫 방문 뒤 오프라인으로 바꿔도 7개 주제가 열림, 320px, 어두운 화면에서 미소 배경이 투명.

## 6. 성공 확인
- `npm test` 전체 통과, `browser_check.py` `ALL CHECKS PASSED`.
- 사용자가 실제 휴대폰에서 홈 화면에 추가하고 비행기 모드로 열어 본다 (세션에서는 실제 아이폰을 시험할 수 없다).

## 7. 제작자에게 맡기는 것
- 메뉴 아이콘 모양(직접 그린 단순 SVG), 미소 그림 크기와 위치, 진행률 막대 모양.
- 오프라인 작업자의 세부 저장 전략(미리 받기 + 같은 주소는 저장본 먼저 보여 주고 뒤에서 새로 받기).
