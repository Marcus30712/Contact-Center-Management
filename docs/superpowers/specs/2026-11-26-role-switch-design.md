# 상단 직급 선택 (2026-11-26) — 짧은 설계

## 왜
- 홈 왼쪽 위의 "Queuecraft" 글자는 바로 아래 큰 제목 "큐크래프트 / Queuecraft"와 겹칩니다.
- 직급을 바꾸려면 설정까지 가야 합니다. 바꾼 뒤에도 설정 페이지에 머물러서, 바뀐 홈을 보려면 다시 홈으로 가야 합니다.

## 정한 것 (사용자 승인)
- "Queuecraft" 글자가 있던 12개 페이지(홈, 설정, 길잡이, SME 길잡이, 찾아보기, 용어집, 참고자료, 인력 계산기, 복습 퀴즈, 오늘의 연습, 엑셀, 개인정보처리방침)는 그 자리에 직급 선택 상자를 넣습니다(A안).
- 강의 페이지 9개의 왼쪽 위 강의 이름은 그대로 둡니다.
- 선택 상자에서 직급을 고르면 저장하고 홈 맨 위로 이동합니다. 설정에서 바꿔도 똑같이 홈으로 이동합니다.

## 접근 방식
- 고른 안: 모든 페이지가 이미 불러오는 `shared/appbar.js`가 페이지의 빈 자리(`data-role-slot`)에 선택 상자를 그립니다. 그리는 코드는 `shared/role-switch.js` 하나에 둡니다.
- 버린 안 1: 페이지마다 app.js에 넣기. 12곳을 고쳐야 하고, 화면 코드가 없는 페이지도 있습니다.
- 버린 안 2: 직접 만든 펼침 메뉴. 키보드·화면 읽기·모바일 대응을 새로 만들어야 합니다. 기본 `<select>`는 휴대폰의 기본 선택 화면을 씁니다.

## 세부
- 보기와 이름표는 이미 승인된 문구 `ROLE_NAMES`, `ROLE_UI.settingsHeading`("내 직급" / "My role")를 다시 씁니다. 새 문구는 없습니다.
- 처음 선택값은 `loadRole`입니다. 저장한 적이 없으면 TL입니다.
- 언어 전환(`<html lang>` 변경)과 `ROLE_EVENT`가 오면 선택 상자를 다시 그립니다.
- 저장소가 막혀도 홈으로는 이동합니다. 직급은 저장되지 않으며, 지금 설정 화면과 같은 동작입니다.
- 홈 첫 방문 때 나오는 직급 선택 창은 그대로 둡니다.
