# 시작 화면: 시간대·요일에 맞는 미소의 인사 — 설계와 한국어 문안

작성일: 2026-11-22 · 상태: 승인됨 (2026-11-22)

## 1. 의도와 이유

"리아와 파이썬"처럼 앱을 열면 먼저 나오는 시작 화면을 둔다. 사용자의 목적(2026-11-22): **접속하는 시간대를 파악해, 접속할 때마다 알맞은 인사나 안부를 시작 화면에서 보여 주기.** 인사는 시간대와 요일을 함께 본다(사용자 선택 B). 컨택센터는 교대 근무가 많으므로 밤·새벽 인사는 야간 근무를 배려하는 안부로 쓴다.

## 2. 목표 · 비목표 · 반목표

**목표**
- 홈(`./`)을 열면 시작 화면이 홈 위를 덮는다: 미소 얼굴, 로고, 한 줄 소개, 인사 말풍선, 오프라인 준비 표시, [시작하기], 언어 전환.
- 인사는 휴대폰 시계의 시간대(6개)와 요일(월요일 아침, 금요일 오후·저녁, 주말)로 고르고, 같은 묶음 안에서는 무작위로 하나.
- 한 번 방문하는 동안 한 번만 뜬다(앱을 완전히 닫았다 열면 다시). [시작하기]로 닫히고, 처음 온 사람은 그 뒤 기존 튜토리얼이 이어진다.
- 한국어·영어, 320px~PC, 밝은·어두운 화면, 키보드·화면 낭독기, 움직임 줄이기 설정을 지킨다.

**비목표**
- 마지막 접속 날짜 등 새 정보 저장(사용자 선택 B: 저장 없음). 이름 입력·개인화.
- 레슨·SOP·길잡이 링크 등 다른 주소로 바로 들어올 때 시작 화면 띄우기(사용자 선택 A).
- 홈의 기존 미소 인사 문구 변경, 버전 번호 표시.
- 계절·공휴일·날씨 인사.

**반목표**
- 바로 공부하려는 사람을 막는 것: 한 번의 탭(또는 Enter)으로 닫히고, 같은 방문 안에서는 다시 뜨지 않는다.
- 공부를 재촉하거나 죄책감을 주는 말("오늘 안 했어요" 등). 밤·새벽에는 쉬라고 권한다.
- 특정 국가의 법·근로 제도 언급, "진상", 3문장을 넘는 문구, 출처 없는 숫자.

## 3. 접근 방식

| 방법 | 내용 | 결정 |
|---|---|---|
| A. 홈에 겹쳐 띄우기 | 홈 주소로 들어오면 덮개 화면, [시작하기]로 걷힘. 방문당 한 번 | **사용자 선택** — 앱을 열 때 인사, 바로 레슨으로 가는 사람은 막지 않음 |
| B. 별도 시작 페이지 | 홈 화면 앱이 그 페이지에서 시작 | 페이지가 한 번 더 바뀌고, 홈 주소로 바로 오면 못 봄 |
| C. 어느 페이지든 띄우기 | 레슨 주소로 와도 먼저 뜸 | 길잡이 흐름이 끊김 |

## 4. 동작

- **언제:** 앱을 **홈에서 시작할 때**만 띄운다: 주소가 해시 없는 홈(`./`)이고, 앱의 다른 페이지에서 넘어온 것이 아닐 때(같은 사이트에서 온 이동이 아님), 그리고 새로 연 것일 때(새로고침·뒤로 가기는 제외). 아래 메뉴의 배우기·찾아보기(`./#learn`, `./#browse`)나 다른 페이지에서 홈으로 온 경우는 띄우지 않는다 — 공부하러 가는 길을 막지 않기 위해서다(설계자 판단). 아무것도 저장하지 않는다: 같은 방문 안의 새로고침·뒤로 가기·다른 페이지에서의 이동은 브라우저가 알려 주는 이동 종류와 이전 주소로 가린다(개인정보처리방침의 저장 항목이 늘지 않게 — 2026-11-22 구현 중 결정). 주소에 `?tour=1`(튜토리얼 다시 보기)이 있으면 띄우지 않는다.
- **시간대**(휴대폰 시계, 시작 시각 포함): 새벽 0~5시, 아침 5~11시, 점심 11~14시, 오후 14~18시, 저녁 18~22시, 밤 22~24시.
- **요일 인사가 시간대 인사보다 먼저:** 월요일 아침 → 월요일 묶음, 금요일 오후·저녁 → 금요일 묶음, 토·일 아침~저녁(5~22시) → 주말 묶음. 주말 밤·새벽은 시간대 묶음(야간 근무 배려)을 쓴다.
- **고르기:** 묶음 안에서 무작위 하나. 묶음마다 미소 표정이 정해져 있다(아래 표).
- **오프라인 표시:** 설정 화면과 같은 판단을 쓴다(두 화면이 서로 다른 말을 하지 않게). 오프라인 준비가 끝났으면 "오프라인에서도 볼 수 있어요", 등록은 됐고 아직 받는 중이면 "오프라인 준비 중…". 지원하지 않거나, 등록이 안 됐거나 실패했으면(사생활 보호 모드 등) 줄을 숨긴다 — 끝나지 않는 "준비 중"을 보이지 않기 위해서다(설계자 판단).
- **닫기:** [시작하기] 또는 Enter/Esc. 닫힐 때 덮개가 사라지고(움직임 줄이기 설정이면 즉시) 포커스는 홈의 첫 제목으로 간다. 처음 온 사람이면 그 뒤 기존 튜토리얼을 시작한다(튜토리얼은 시작 화면이 닫힐 때까지 기다린다).
- **접근성:** 덮개는 대화상자(`role="dialog"`, `aria-modal`), 제목은 로고. 열리면 대화상자 자체에 포커스를 둔다(누르지 않은 버튼에 노란 포커스 테두리가 보이지 않게 — 2026-11-22 구현 중 결정). Enter·Esc로 닫힌다. 뒤의 홈과 메뉴는 닫힐 때까지 누를 수 없다. 언어 전환은 덮개 안에서도 된다.

## 6. 성공 확인

- 인사 고르기: 시각·요일별 경계(4:59/5:00, 10:59/11:00, 13:59/14:00, 17:59/18:00, 21:59/22:00, 23:59/0:00, 월요일 10:59/11:00, 금요일 13:59/14:00·21:59/22:00, 토요일 4:59/5:00·21:59/22:00)에서 맞는 묶음이 나온다. 시계와 무작위 값은 테스트에서 넣는다.
- 문안: 화면과 이 문서가 한 글자도 다르지 않다(한국어·영어). 금지어·3문장·숫자 규칙.
- 홈: 처음 열면 시작 화면 → [시작하기] → 홈(첫 방문이면 튜토리얼). 같은 방문에 다시 홈으로 와도 안 뜬다. `?tour=1`이면 안 뜬다. 레슨 주소로 바로 오면 안 뜬다.
- 브라우저 점검: 320·390·1280px, 한국어·영어, 어두운 화면, 넘침 없음, 키보드로 닫기, 콘솔 오류 없음.
