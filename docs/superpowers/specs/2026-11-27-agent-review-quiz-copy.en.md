## 퀴즈 3. 상담사 복습 퀴즈

### 문제 1

| 항목 | English |
|---|---|
| 질문 | During nesting, a customer asks Jimin for a refund over the refund limit (Example). She has checked the limit in the knowledge base, and the colleague next to her says, "Just give it to them, it's not that much." What does she do? |
| 보기 a (정답) | Sum up the limit she checked and the customer's situation, and ask Harin for the approval it needs. |
| 보기 b (오답) | Process the refund as is, as the colleague said. |
| b 피드백 | A call that needs approval goes to the SME, not the next seat. |
| 보기 c (오답) | Put the customer on hold and just ask Harin, "What do I do with this?" |
| c 피드백 | Saying what you checked and what you need gets an answer right away, with no follow-up questions. |
| 해설 | Build on what you looked up yourself, and ask the SME for approval with everything in one message. |
| 관련 레슨 | Agent First Steps lesson 3 · OJT and Nesting: How to Ask (../agent/#nesting-0) · Agent SOP · Requesting an Escalation (../agent-sop/#request-0) |

### 문제 2

| 항목 | English |
|---|---|
| 질문 | A customer angry about a late delivery was only raising their voice at first, but now they have started swearing at Jimin. What does she do? |
| 보기 a (오답) | A customer's anger is aimed at the situation, so put up with the swearing to the end. |
| a 피드백 | You listen to anger, but swearing isn't something to put up with; it has a set procedure. |
| 보기 b (정답) | The swearing has started, so warn the customer with the center's set wording. |
| 보기 c (오답) | End the call right away without a warning. |
| c 피드백 | Hanging up without a warning leaves the customer without a reason and skips the center's procedure. |
| 해설 | Listen to and acknowledge an angry customer. Once swearing starts, follow the order: warn, get approval if needed, then announce the end of the call. |
| 관련 레슨 | Agent First Steps lesson 5 · Difficult Customers (../agent/#customers-0) · Agent SOP · Handling Abusive Callers and Ending the Call (../agent-sop/#abuse-0) |

### 문제 3

| 항목 | English |
|---|---|
| 질문 | Jimin ran a fever all night and doesn't think she can make it in this morning. Her shift starts in three hours (Example), and her colleagues are in the team group chat. What does she do? |
| 보기 a (오답) | Just post "Can't make it today" in the group chat and go back to sleep. |
| a 피드백 | A message with no set recipient may reach the team leader late, or not at all. |
| 보기 b (오답) | Contacts pile up on the others when someone is out, so take medicine and push through to work. |
| b 피드백 | Pushing through while sick can keep you out longer. Resting by the procedure helps the team too. |
| 보기 c (정답) | Tell Sujin right away the way the team has set up, and send the doctor's note the same day. |
| 해설 | Report early, the set way, to the set person, and send the documents by the center's deadline. |
| 관련 레슨 | Agent First Steps lesson 7 · Attendance and Schedules (../agent/#attendance-0) · Agent SOP · Reporting an Absence or Sick Day (../agent-sop/#absence-0) |

### 문제 4

| 항목 | English |
|---|---|
| 질문 | In this week's evaluation, Jimin lost a lot of points for missing ID verification and some on the guidance item. She agrees with the ID verification points, but not with the guidance ones. What does she do? |
| 보기 a (오답) | Message QA right away and argue that both items are unfair. |
| a 피드백 | Rather than arguing from feelings, gather evidence and dispute through the set route. |
| 보기 b (정답) | Fix ID verification right away, and dispute the guidance points with the recording as evidence. |
| 보기 c (오답) | Follow the one-fix-a-week rule and fix only the guidance item this week. |
| c 피드백 | A critical error like missing ID verification gets fixed right away, without waiting its turn. |
| 해설 | Fix critical errors right away. For points you can't agree with, ask for a second look with the recording as evidence, through the team leader and by the set deadline. |
| 관련 레슨 | Agent First Steps lesson 6 · The Weekly Score Review (../agent/#review-0) · Agent SOP · Disputing a Quality Score (../agent-sop/#dispute-0) |

### 문제 5

| 항목 | English |
|---|---|
| 질문 | At the morning huddle, Jimin heard the client's refund period has changed, but the knowledge base still shows the old period. Just then, a customer asks about the refund period. What does she do? |
| 보기 a (오답) | Give the old period from the knowledge base, the official document. |
| a 피드백 | The document may not have caught up with the huddle yet. Giving the old period means the customer will have to contact you again. |
| 보기 b (오답) | Fix the knowledge base article herself, deciding which one is right. |
| b 피드백 | You don't fix the document yourself; you report it so the owner can correct it. |
| 보기 c (정답) | Go by her huddle notes, and tell Harin the document is different. |
| 해설 | Apply the update you heard at the huddle, and report any difference in the document to the SME so everyone guides customers the same way. |
| 관련 레슨 | Agent SOP · Applying a Client Update from the Huddle (../agent-sop/#huddle-0) · Agent SOP · Reporting a Knowledge Base Error (../agent-sop/#kbreport-0) |

### 문제 6

| 항목 | English |
|---|---|
| 질문 | In Jimin's first week after Go Live, the contact system freezes mid-call. Her neighbor's screen seems frozen too, and the customer is waiting on the line. What does she do? |
| 보기 a (정답) | If the set first fix doesn't help, tell Harin or the team leader right away and let the customer know. |
| 보기 b (오답) | It's her first week and probably her mistake, so quietly reboot on her own without telling the customer. |
| b 피드백 | If the set first fix doesn't help, don't blame yourself; report it right away. Telling the customer what's happening keeps the wait from dragging on. |
| 보기 c (오답) | Promise the customer it will be fixed within 10 minutes (Example) and ask them to wait. |
| c 피드백 | An agent can't know the recovery time, so don't make a promise you can't keep. |
| 해설 | If you suspect an outage, tell the SME or the team leader right away. Give the customer the set wording and don't promise a recovery time. |
| 관련 레슨 | Agent First Steps lesson 4 · Go Live and the First Call (../agent/#golive-0) · Agent SOP · Responding to a System Outage (../agent-sop/#outage-0) |
