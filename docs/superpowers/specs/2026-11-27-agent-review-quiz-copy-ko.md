# 상담사 복습 퀴즈 — 한국어 문안 초안

작성일: 2026-11-27 · 상태: 승인됨 (2026-11-27) · 바탕: `2026-11-25-role-review-quiz-design.md`, `2026-11-25-review-quiz-copy-ko.md`

팀장·직무전문가 복습 퀴즈와 같은 원칙을 따릅니다.
- 6문제, 보기 3개, 정답 하나입니다.
- 문제마다 레슨 2개 이상을 함께 떠올려야 풀리는 장면입니다.
- 오답 피드백과 해설은 한두 문장으로 씁니다.
- 출처 없는 숫자에는 "예시"를 붙입니다.
- 5개 이상 맞히면 통과하고 배지를 받습니다.

등장인물은 상담사 강의와 같습니다. 지민(상담사), 하린(직무전문가), 수진 팀장, 도현(QA)입니다.

## 퀴즈 3. 상담사 복습 퀴즈

### 문제 1

| 항목 | 한국어 |
|---|---|
| 질문 | 네스팅 중인 지민에게 고객이 환불 한도(예시)를 넘는 환불을 요구합니다. 지민은 지식 베이스에서 한도를 확인했고, 옆자리 동료는 "그 정도는 그냥 해 줘도 돼"라고 말합니다. 어떻게 할까요? |
| 보기 a (정답) | 확인한 한도와 고객 상황을 정리해, 승인이 필요하다고 하린에게 묻는다. |
| 보기 b (오답) | 옆자리 동료의 말대로, 그대로 환불을 처리한다. |
| b 피드백 | 승인이 필요한 판단은 옆자리가 아니라 직무전문가에게 묻습니다. |
| 보기 c (오답) | 고객을 보류해 두고, 하린에게 "이거 어떻게 해요?"라고만 짧게 묻는다. |
| c 피드백 | 확인한 것과 필요한 것을 함께 말해야, 다시 묻지 않고 바로 답이 옵니다. |
| 해설 | 스스로 찾아본 것을 바탕으로, 승인이 필요한 일은 직무전문가에게 한 번에 정리해 요청합니다. |

### 문제 2

| 항목 | 한국어 |
|---|---|
| 질문 | 배송이 늦어 화가 난 고객이 처음에는 언성만 높이다가, 이제 지민에게 욕설을 하기 시작했습니다. 어떻게 할까요? |
| 보기 a (오답) | 고객의 화는 상황을 향하니, 욕설도 끝까지 참고 듣는다. |
| a 피드백 | 화는 들어 드리지만, 욕설은 참는 것이 아니라 정해진 절차로 다룹니다. |
| 보기 b (정답) | 욕설이 시작됐으니, 센터가 정한 문구로 경고한다. |
| 보기 c (오답) | 경고 없이 바로 통화를 끊는다. |
| c 피드백 | 경고 없이 끊으면 고객은 이유를 모르고, 센터의 절차도 지키지 못합니다. |
| 해설 | 화난 고객은 듣고 인정합니다. 욕설이 시작되면 경고, 필요하면 승인, 종료 안내 순서를 따릅니다. |

### 문제 3

| 항목 | 한국어 |
|---|---|
| 질문 | 밤새 열이 난 지민은 아침에 출근하기 어렵다고 느낍니다. 근무 시작까지 세 시간(예시) 남았고, 팀 단체 채팅방에는 동료들이 있습니다. 어떻게 할까요? |
| 보기 a (오답) | 단체 채팅방에 "오늘 못 나가요"라고만 남기고 다시 잔다. |
| a 피드백 | 받을 사람이 정해지지 않은 곳에 남기면, 팀장이 늦게 보거나 못 볼 수 있습니다. |
| 보기 b (오답) | 동료가 빠지면 남은 사람에게 문의가 몰리니, 약을 먹고 무리해서 출근한다. |
| b 피드백 | 아픈데 무리하면 더 길게 빠질 수 있습니다. 절차대로 쉬는 것도 팀을 돕는 일입니다. |
| 보기 c (정답) | 정한 방법으로 수진 팀장에게 바로 알리고, 진단서는 당일 안에 보낸다. |
| 해설 | 미리, 정한 방법으로, 정한 사람에게 알리고, 서류는 센터가 정한 기한 안에 보냅니다. |

### 문제 4

| 항목 | 한국어 |
|---|---|
| 질문 | 이번 주 평가에서 지민은 본인 확인 누락으로 크게 감점되었고, 안내 항목에서도 감점되었습니다. 본인 확인 감점은 맞다고 생각하지만, 안내 감점은 납득이 안 됩니다. 어떻게 할까요? |
| 보기 a (오답) | QA에게 바로 메시지를 보내, 두 항목 모두 억울하다고 따진다. |
| a 피드백 | 감정적으로 따지기보다 근거를 모아, 정해진 경로로 이의를 제기합니다. |
| 보기 b (정답) | 본인 확인은 바로 고치고, 안내 감점은 녹취를 근거로 이의를 낸다. |
| 보기 c (오답) | 한 주에 하나만 고친다는 원칙대로, 이번 주는 안내 항목만 고친다. |
| c 피드백 | 본인 확인 누락 같은 치명적 오류는 순서를 기다리지 않고 바로 고칩니다. |
| 해설 | 치명적 오류는 바로 고칩니다. 동의하기 어려운 감점은 녹취를 근거로, 팀장을 거쳐 정해진 기한 안에 다시 검토를 요청합니다. |

|---|---|
| 질문 | 아침 허들에서 고객사의 환불 기간이 바뀌었다고 들었는데, 지식 베이스에는 아직 예전 기간이 그대로 있습니다. 마침 고객이 환불 기간을 묻습니다. 어떻게 할까요? |
| 보기 a (오답) | 지식 베이스가 공식 문서라며, 예전 기간으로 안내한다. |
| a 피드백 | 허들에서 바뀐 내용이 문서에 늦게 반영되었을 수 있습니다. 예전 기간을 안내하면 고객이 다시 연락하게 됩니다. |
| 보기 b (오답) | 어느 쪽이 맞는지 직접 판단해, 지식 베이스 문서를 고쳐 둔다. |

| 해설 | 허들에서 들은 업데이트를 적용하고, 문서와 다른 점은 직무전문가에게 알려 모두가 같은 내용으로 안내하게 합니다. |

| 항목 | 한국어 |
|---|---|
