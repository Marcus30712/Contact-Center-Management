# 내 직급 강의만 보여 주기와 직급별 복습 퀴즈 — 설계 문서

작성일: 2026-11-25 · 상태: 승인됨 (2026-11-25) · 앞선 설계: `2026-11-25-role-select-sme-course-design.md`

## 1. 의도와 이유

두 가지 요청이 있었습니다(사용자, 2026-11-25).

1. **팀장 강의를 듣는 사람이 SME 강의 진도를 볼 필요는 없습니다.** 지금 홈의 "내 학습"은 직급과 상관없이 모든 강의의 진도를 보여 줍니다. 그래서 강의를 다 마친 팀장에게도 "다 마쳤어요" 대신 SME 0/7이 보입니다.
2. **직급별 강의를 다 마치면 복습 삼아 간단한 퀴즈를 내고 싶습니다.**

사용자가 정한 것:
- 퀴즈 문제는 이미 있는 레슨 문제를 다시 쓰지 않습니다. 레슨 여러 개를 함께 떠올려야 풀리는 **상황형 문제를 새로 씁니다**(B). 오늘의 연습이 이미 마친 레슨의 문제를 매일 다시 내고 있어서, 같은 문제로는 복습이 되지 않기 때문입니다.
- 정해진 점수 이상이면 **배지**를 줍니다(B). 못 넘으면 틀린 문제의 레슨을 다시 보고 재도전합니다.
- 퀴즈는 **새 페이지 `review/`**에 둡니다(A).

## 2. 목표 · 비목표 · 반목표

**목표**
- 홈 "내 학습"에는 내 직급 강의와 공통 강의(엑셀)만 보입니다. "다 마쳤어요"도 이 강의들로만 판단합니다.
- 내 직급 강의를 모두 마치면 그 직급의 복습 퀴즈가 열립니다. 팀장은 라이프사이클 6개와 SOP 10개, SME는 SME 첫걸음 7개를 마쳤을 때입니다.
- 퀴즈는 직급마다 새로 쓴 상황형 문제 6개입니다. 보기 3개 객관식이고, 오답마다 피드백, 문제마다 해설, 관련 레슨으로 가는 "다시 보기" 링크가 있습니다.
- 6문제 중 5개 이상(예시 기준 약 80%)을 맞히면 통과합니다. 통과하면 오늘의 연습 배지 "팀장 과정 완주" 또는 "SME 과정 완주"를 받습니다.
- 몇 번이든 다시 풀 수 있고, 최고 점수와 통과 여부를 기기에 저장합니다.

**비목표**
- 상담사·부매니저·매니저 퀴즈. 그 직급의 강의가 생길 때 함께 만듭니다.
- 공식 자격처럼 보이는 수료증, 이름·날짜 표시, 공유 기능.
- 시간 제한, 문제 순서나 보기 순서 섞기, 문제 은행에서 무작위로 뽑기.
- "배우기" 목록에서 다른 직급 강의를 숨기는 것. 다른 직급 강의는 지금처럼 열려 있습니다.

**반목표**
- 직급을 고르지 않은 기존 사용자의 홈이 달라지는 것. 직급을 고르지 않았으면 팀장으로 보므로, 기존 사용자에게는 SME 진도만 사라집니다.
- 퀴즈 때문에 강의를 다시 보지 못하거나, 퀴즈를 통과해야만 다른 기능이 열리는 구조.
- 통과 점수를 공식 기준처럼 쓰는 것. 화면에는 "복습용"이라고 밝힙니다.

## 3. 접근 방식

| 방법 | 내용 | 결정 |
|---|---|---|
| A. 새 페이지 `review/` | 직급별 문제 데이터 파일 하나, 기존 체크포인트 문제 엔진 재사용, 결과를 저장하고 연습 배지가 읽음 | **사용자 선택**: 두 강의에 걸친 팀장 퀴즈를 담을 수 있고, 다음 직급을 붙이기 쉽습니다 |
| B. 오늘의 연습 안에 넣기 | 새 페이지 없이 연습 화면에 섹션 추가 | 매일 3문제와 시험 성격의 퀴즈가 한 화면에 섞이고, 연습 화면이 이미 가득 찹니다 |
| C. 각 강의의 마지막 레슨 | 레슨 엔진에 그대로 붙이기 | 팀장 퀴즈가 두 강의에 걸쳐 있어 어디에 붙일지 애매하고, 레슨 형식(다이어그램, 스텝 6개 이상)에 억지로 맞춰야 합니다 |

## 4. 무엇이 바뀌나

### 4.1 홈 "내 학습" (요청 1)
- 보여 주는 강의: 내 직급 강의, 그리고 직급 표시가 없는 공통 강의(엑셀).
  - 팀장(또는 직급을 고르지 않음): 라이프사이클, SOP, 엑셀
  - SME: SME 첫걸음, 엑셀
  - 강의가 없는 직급(상담사·부매니저·매니저): 엑셀만 보여 주고, 지금처럼 "준비 중" 안내를 둡니다.
- "다 마쳤어요"는 보이는 강의를 기준으로 판단합니다. 처음 방문 안내(라이프사이클 레슨 1 / SME 레슨 1)는 그대로입니다.
- "배우기" 카드 목록은 바뀌지 않습니다(모든 강의, 내 직급 먼저).

### 4.2 복습 퀴즈 열기
- 홈 "내 학습": 내 직급 강의를 모두 마치면 강의 줄 아래에 퀴즈 카드가 나타납니다. 통과 전에는 "복습 퀴즈 풀기", 통과 뒤에는 최고 점수와 "다시 풀기"를 보여 줍니다. 강의를 다 마치기 전에는 카드를 보여 주지 않습니다.
- `review/` 페이지: 강의가 있는 직급(팀장, SME)의 퀴즈를 내 직급 먼저 보여 줍니다. 아직 강의를 다 마치지 않은 퀴즈는 잠겨 있고, 남은 레슨 수와 이어서 볼 레슨 링크를 보여 줍니다. 직급과 상관없이 잠금 조건만 맞으면 누구나 풀 수 있습니다(직급으로 막지 않는다는 원칙).

### 4.3 퀴즈 진행
- 한 화면에 한 문제씩 진행합니다(문제 i / 6). 보기를 고르면 바로 정답 여부, 오답 피드백, 해설을 보여 주고 "다음 문제"로 넘어갑니다. 레슨 체크포인트, 오늘의 연습과 같은 방식입니다.
- 틀린 문제에는 관련 레슨의 "다시 보기" 링크를 둡니다. 문제마다 관련 레슨을 1~2개 지정합니다.
- 결과 화면에는 점수(예: 6문제 중 5개), 통과 여부, 틀린 문제와 다시 볼 레슨 목록, "다시 풀기" 버튼이 있습니다. 처음 통과하면 받은 배지를 보여 줍니다.
- 김미소가 오늘의 연습처럼 표정으로 반응합니다(정답, 오답, 통과, 미통과).
- 도중에 페이지를 떠나면 그 회차는 저장하지 않습니다. 끝까지 푼 회차만 기록합니다.

### 4.4 저장, 백업, 초기화
- 저장 키: `queuecraft:review:v1`. 값은 `{ tl: { best, total, passed }, sme: { … } }`입니다.
- 기록 백업에 넣고, 학습 초기화로 지웁니다(학습 기록이기 때문).
- 개인정보처리방침의 저장 항목 문구에 복습 퀴즈 결과를 더합니다(문안 단계에서 확정).

### 4.5 배지
- 오늘의 연습 배지에 "팀장 과정 완주"(`review-tl`)와 "SME 과정 완주"(`review-sme`) 두 개를 더합니다(10개 → 12개). 조건은 "해당 복습 퀴즈 통과"입니다.
- 퀴즈 결과 화면에서 처음 통과하면 바로 배지를 받습니다. 연습 화면에서도 같은 조건으로 확인합니다.
- README의 "배지 10개" 문구를 고칩니다.

### 4.6 문제 문안
- 직급마다 상황형 6문제를 새로 씁니다. 각 문제는 레슨 2개 이상의 내용을 함께 써야 풀리는 장면입니다.
  - 팀장: 라이프사이클과 SOP를 섞습니다(예: 실무 체험 중인 신입의 반복 실수 → 코칭 → PIP 판단).
  - SME: SME 첫걸음 7개를 섞습니다(예: 요청이 몰린 순간에 동기 선임과 신입이 동시에 부름).
- 형식은 레슨 체크포인트와 같습니다: 질문, 보기 3개, 정답 1개, 오답 피드백 한 문장씩, 해설.
- 지금까지처럼 한국어 문안 문서를 먼저 확인받고, 그다음 영어를 붙입니다. 테스트가 문서와 코드의 한국어를 대조합니다.

## 5. 진행 순서

1. 이 설계 승인
2. 퀴즈 한국어 문안(직급별 6문제, 화면 문구, 배지 이름, 방침 문구) 확인
3. 구현 계획
4. 구현: 홈 "내 학습" 정리 → 퀴즈 저장·배지 → `review/` 페이지 → 홈 퀴즈 카드
5. 영어 문안
6. 같은 브랜치(PR #87)에 커밋하고 푸시. 커밋과 푸시는 승인 후에 합니다.

## 6. 완성 기준

- 팀장을 고른 사람(또는 직급을 고르지 않은 사람)의 "내 학습"에 SME 진도가 보이지 않고, 라이프사이클·SOP·엑셀을 다 마치면 "다 마쳤어요"가 보입니다. SME를 고른 사람에게는 라이프사이클·SOP 진도가 보이지 않습니다.
- 내 직급 강의를 다 마치기 전에는 퀴즈 카드가 없고, `review/`에서는 그 퀴즈가 잠겨 있습니다.
- 6문제 중 5개 이상 맞히면 통과하고 배지를 한 번만 받습니다. 4개 이하면 통과하지 못하고 다시 풀 수 있습니다. 최고 점수는 낮은 점수로 덮이지 않습니다.
- 백업 파일에 퀴즈 결과가 들어가고, 학습 초기화로 지워집니다.
- 저장이 막힌 브라우저에서도 퀴즈를 풀 수 있습니다(결과만 남지 않음).
- 전체 테스트와 브라우저 점검이 통과합니다.

## 7. 빌더에게 맡기는 것 (제안한 결정)

- 화면은 오늘의 연습 페이지의 문제 화면과 같은 모양을 씁니다. 문제 데이터는 레슨 체크포인트와 같은 형식이라 `gradeAnswer`를 그대로 씁니다.
- 문제 데이터 파일: `review/data.js`. 직급 id를 키로 하고, 문제마다 `lessons`(관련 레슨 주소 목록)를 둡니다.
- 잠금 판단은 홈과 `review/`가 같은 함수를 씁니다. 각 직급이 어떤 강의를 마쳐야 하는지는 강의 목록에 붙은 직급 표시를 다시 씁니다.
