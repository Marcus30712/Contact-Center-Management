# CX 2회차 (CX Replay)

**한국어** · [English](README.en.md)

**👉 [서비스 바로가기 / Open the app](https://marcus30712.github.io/Contact-Center-Management/)**

상담사부터 매니저까지, 컨택센터의 새 자리를 미리 배우는 학습 앱입니다. 처음 열 때 준비하는 직급(상담사·SME·팀장·부매니저·매니저)을 고르면 그 직급의 강의가 먼저 보이고, 설정에서 언제든 바꿀 수 있습니다. 컨택센터 운영 관리를 주제별로 다루는 인터랙티브 학습 자료 모음입니다. 휴대폰 홈 화면에 추가하면 앱처럼 쓰고, 한 번 연 뒤에는 오프라인에서도 볼 수 있습니다. 선배 매니저 김미소가 첫 화면에서 내 학습을 이어 가도록 안내합니다.

| 상담사 커리어 라이프사이클 / Agent Career Lifecycle | [`agent-career/`](agent-career/) | 상담사가 지향할 수 있는 다음 자리 5개 레슨: 직무전문가, QA, 트레이너, 팀장, 그리고 어느 자리든 공통으로 보는 준비 (한국어/영어) |
| 상담사 라이프사이클 / The Agent Lifecycle | [`agent-lifecycle/`](agent-lifecycle/) | 신입 팀장을 위한 6단계 강의 (한국어/영어) |

| SME 첫걸음 / SME First Steps | [`sme/`](sme/) | 상담사에서 막 SME가 된 사람을 위한 7개 레슨: 첫날, 신입·기존 상담사·동료였던 선임·팀장 서포트, 요청이 몰릴 때, 팀에 지식 돌려주기 (한국어/영어) |

| SME SOP 라이브러리 / SME SOP Library | [`sme-sop/`](sme-sop/) | SME가 맡는 표준 절차 8개: 에스컬레이션 승인, 스크러빙, 상담 트렌드 요약 보고, 출석 관리 대행, 고객사 업데이트 허들, 캘리브레이션 참여와 기준 전달, VOC 리포팅, 지식 베이스 업데이트 요청 (한국어/영어) |

- 첫 화면: `index.html` (김미소 인사, 내 학습, 오늘의 연습, 상황별 길잡이, 배우기). 모든 직급이 같은 틀이고, 길잡이와 배우기 카드만 직급(`home/role-home.js`)에 따라 바뀝니다. 아직 없는 강의는 "준비 중" 카드로 보입니다. 찾아보기 카드는 별도 페이지 `browse/`에 있습니다. 모든 페이지 아래에 공통 메뉴(홈·배우기·길잡이·찾아보기·설정)가 있습니다 (`shared/`)
- 앱 설치·오프라인: `manifest.webmanifest`, `sw.js`. 화면 파일을 바꾸면 `python3 tools/sw_list.py`로 `sw.js`를 다시 만듭니다
- 캐릭터 김미소 이미지: Marcus Shim이 Google Gemini로 생성. CC BY-NC-ND 4.0을 따릅니다 (`assets/miso/`, 원본 `art/miso/`)
- 설계 문서와 계획: `docs/superpowers/`
- 업데이트 내역: [`LOG.md`](LOG.md)
- 새 주제는 폴더를 하나 추가하고 `home/data.js`의 목록에 카드 한 장을 더하면 됩니다.

빌드가 필요 없는 정적 사이트입니다. GitHub Pages로 배포하려면 저장소 Settings → Pages에서 기본 브랜치의 루트 폴더(`/`)를 선택합니다.
